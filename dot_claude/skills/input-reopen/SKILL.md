description: Переоткрыть панель ввода Neovim под панелью Claude Code этой сессии (herdr), когда nvim завис или не реагирует на клавиши. Вызывается пользователем командой /input-reopen.
disable-model-invocation: true
---

Выполни единственную команду и коротко сообщи результат пользователю по-русски,
без вопросов и других шагов:

```sh
bash "$HOME/.claude/hooks/herdr-claude-input.sh" reopen </dev/null
```

- Код выхода 0 и строка «панель ввода открыта заново» — ответь «Панель ввода открыта заново».
- Иначе (код выхода не 0 — причина из stderr хука одной фразой; код 0 без этой строки — хук вне области действия, панель не открыта) — сообщи, что панель не открыта, и причину.
