# Источники пакетов

Документ сводит в одну таблицу все программы машины: явно установленные
пакеты pacman (`pacman -Qeq`, 283; зависимости не входят), пакеты AUR,
инструменты mise, установки cargo и ручные. Для каждой программы показано,
из каких источников она доступна и из какого стоит сейчас. Цель —
рабочий перечень при перестройке источников установки: единый источник
для каждой программы и обновление одной командой `paru -Syu` вместо набора
`mise upgrade`, `cargo install` и ручных скачиваний.

Версии сняты 2026-10-29. Правило выбора источника предложено и ещё
не оформлено записью решения; когда оно будет принято, ляжет в
`docs/decisions/` (номер следующий после 0008), а здесь останется ссылка.

## Правило выбора источника

1. Предпочитается пакет официальных репозиториев (pacman: core, extra
   и зеркала CachyOS).
2. Пакет AUR берётся, только если в репозиториях пакета нет либо
   репозиторий отстаёт от AUR (или от последней версии upstream, если
   AUR-пакет `-bin` ей равен) не меньше чем на минорную версию (средняя
   цифра в X.Y.Z; для версий-дат, как у wezterm и yazi, — на месяц
   и больше; для программ с одним числом версии — на следующее число).
   Пакеты `-git` и `nightly` кандидатами не считаются, кроме случая,
   когда другого пакета программы нет.
3. mise, cargo, flatpak, AppImage и ручная сборка из git допустимы,
   только если программы нет ни в репозиториях, ни в AUR.

Таблица от правила не зависит: она показывает только нынешнее состояние
и доступные версии. Рекомендации по правилу собраны под таблицей.

## Таблица

Редактируемый план перестройки с отметками целевых источников — [`package-sources-plan.md`](package-sources-plan.md).

Каждая ячейка источника описывает программу в этом источнике.
Чекбокс `[x]` — программа сейчас установлена из этого источника, с версией
установки; `[x] 1.4.0 → 1.4.3` — в источнике есть более новая версия
(для pacman это пакет, ждущий обновления репозитория). Чекбокс `[ ]` —
источник есть, но программа оттуда не стоит; после него указана последняя
версия в источнике, а для AUR, flatpak и pacman при отличии от имени
программы — ещё и имя пакета: `[ ] herdr-bin 0.9.5`. «—» — в источнике
программы нет (для AUR — или есть только пакет `-git`). Последние
версии заполнены в каждой колонке у каждой строки. Колонка «git»
объединяет установки вручную: сборку из git, скачанный бинарник или
установщик, `uv tool` и глобальные пакеты bun; в ней же последний тег
upstream. Установки AppImage отмечаются в своей колонке. Ключ строки —
имя программы; программа с несколькими установками занимает несколько
строк (`node 26`, `node 20, 22, 24`). Строки отсортированы по алфавиту.

Как сняты версии. pacman — `pacman -Si` (первый из репозиториев, то есть
cachyos, если пакет есть и там); AUR — `paru -Si` по имени пакета и по
имени с `-bin`; mise — `mise registry` (есть ли имя) и `mise latest`;
cargo — API crates.io по точному имени крейта, `max_stable_version`;
крейт принимается, только если его `repository` или `homepage` совпадает
с upstream пакета (поле URL в `pacman -Si` и `paru -Si`), одноимённые
чужие крейты считаются отсутствием; flatpak — `flatpak search` с совпадением
по имени приложения или последнему компоненту идентификатора; AppImage
и git — `gh api` (последний релиз и его файлы `.AppImage`, при отсутствии
релизов — последний тег) для upstream на github.com, API проекта для
upstream на GitLab. Для upstream вне GitHub и GitLab (сайты проектов,
kernel.org, freedesktop.org, sourceforge и другие) тег не снимался: git
и AppImage там «—».

Охват. Строки собраны по командам, по ним же полноту можно проверить
заново: `pacman -Qeq` (явные пакеты, 283), `pacman -Qm` (AUR, 4),
`mise ls` (51 запись, включая закреплённые версии и установки вне
`[tools]`: groovy, java, poetry, pipx:poetry, ruff, rust, vault, yarn),
`cargo install --list` (3), `uv tool list` (py-spy), `bun pm ls -g`
(OpenSpec), `npm ls -g` (corepack и npm входят в node, отдельных строк
нет), `flatpak list --app` (2), AppImage и бинарники в `~/.local/bin`,
`/usr/local/bin` и `/opt`. Пусто и в таблице не представлено: deno
(глобальные пакеты), pip --user, go, gem, snap, pipx. Свои скрипты
в `~/.local/bin` и `/usr/local/bin` (mkinitcpio, remove-nvidia и подобные)
программами не считаются. Вне таблицы остаются плагины Neovim (lazy.nvim,
85 штук) и плагины Claude Code: они зависимости своих конфигов.
