# Когда в репозитории появится Hyprland с вариантами размытия

## Вопрос

В каком выпуске Hyprland, доступном через pacman, появится поле
`decoration.blur.variant`, и какой из вариантов размытия подойдёт
окнам сессии вместо dual kawase.

## Что мешает решить сейчас

Установленный Hyprland 0.56.2 (репозиторий `cachyos-extra-v3`, та же
версия, что и последний выпуск проекта) знает только алгоритм dual kawase:
`hyprctl getoption decoration:blur:variant` отвечает «no such option».
Варианты размытия влиты в ветку разработки после выпуска 0.56.2
(pull request hyprwm/Hyprland #15661 «renderer/gl: implement swappable blur
variants») и выйдут с 0.57.0, а срока выпуска у проекта нет: расписания
Hyprland не ведёт, у вехи 0.57 на GitHub даты нет. Сборка `hyprland-git`
из AUR отвергнута решением пользователя: ради размытия нестабильную
сборку композитора в систему не тянуть.

## Условие пересмотра

В репозитории pacman появился Hyprland 0.57.0 или новее
(`pacman -Si hyprland`), и система на него обновлена.

Проверять специально не нужно: обновление придёт обычным `pacman -Syu`,
а смена минорной версии видна в его выводе.

## Контекст

Размытие сессии задано в `dot_config/hypr/hyprland.lua`, блок
`decoration.blur`: dual kawase с `size = 3` в три прохода, `vibrancy`
по умолчанию; подобрано пользователем на глаз. Размытие действует только
у окна в фокусе (правило окон `blur-focused`), окно без фокуса
полупрозрачное без размытия, браузеры, плееры, игры и модальные диалоги
непрозрачные. Те же числа размытия действуют у панели Quickshell и окна
askpass (правила слоёв `panel-blur`, `askpass-blur`): отдельных значений
для слоёв у Hyprland нет.

По вики Hyprland варианты поля `variant`: `kawase` (по умолчанию),
`acrylic`, `aurora`, `drops`, `fluid_jar`, `frost`, `haze`,
`heat_shimmer`, `prism`, `ripple`, `water`; у вариантов на основе стекла
(`aurora`, `drops`, `heat_shimmer`, `prism`) есть подраздел
`decoration.blur.glass` с полями `refraction`, `roughness`, `size`.
Вики предупреждает, что варианты заметно нагружают видеокарту
и процессор.

## Что действует до решения

Блок `decoration.blur` остаётся на dual kawase; поле `variant` в конфиг
не вносится: Lua-конфиг 0.56.2 неизвестное поле отвергнет или
проигнорирует, а проверить его действие нечем. Подбор силы размытия идёт
только полями `size`, `passes`, `vibrancy`, `contrast`, `brightness`,
`noise`.

## Возможные исходы

- Выпуск пришёл, вариант подошёл: поле `variant` и, при необходимости,
  блок `glass` добавляются в конфиг коммитом, запись удаляется.
- Выпуск пришёл, варианты не понравились или слишком тяжелы для
  видеокарты: запись удаляется, dual kawase остаётся, причина — строкой
  в комментарии блока `decoration.blur`.
