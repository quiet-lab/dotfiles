# План перестройки источников пакетов

Рабочий план перестройки: пользователь ставит `[x]` в колонке целевого
источника, по одной отметке на строку. Снимок нынешнего состояния
и правило выбора лежат в [`package-sources.md`](package-sources.md);
снимок не правится, правки идут только сюда. Обозначения `—` и `н/и`,
состав строк и колонок те же, что в снимке, но в каждой ячейке указана
одна доступная версия, без стрелок. Отметки предзаполнены по правилу
из снимка (пакеты pacman без изменений остаются на pacman, программы
без пакета в репозиториях идут на AUR, свои проекты и закреплённые версии
остаются там, где стоят); пользователь переставляет их по своему выбору.
