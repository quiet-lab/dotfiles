# План перестройки источников пакетов

Рабочий план перестройки: пользователь ставит `[x]` в колонке целевого
источника, по одной отметке на строку. Снимок нынешнего состояния
и правило выбора лежат в [`package-sources.md`](package-sources.md);
снимок не правится, правки идут только сюда. Состав строк и колонок
те же, что в снимке; «—» — в источнике программы нет.

Обозначения ячейки. `[x]` — желаемый источник, в строке ровно одна;
отметки предзаполнены по правилу из снимка (пакеты pacman без изменений
остаются на pacman, программы без пакета в репозиториях идут на AUR,
свои проекты и закреплённые версии остаются там, где стоят);
пользователь переставляет их по своему выбору. `●` — программа сейчас
установлена из этого источника, в строке ровно один `●` (у дубля mise
и pacman он стоит у mise: дубль снимается). Версия — последняя в источнике;
в ячейке с `●` перед ней стоит установленная: `[ ] ● 1.4.0 → 1.4.3`, а при
равенстве версий — `[ ] ● 1.4.0`. `[x]` и `●` бывают в одной ячейке:
`[x] ● 1.4.0 → 1.4.3`. Работа по перестройке — строки, где `[x]` и `●`
стоят в разных колонках, и ячейки с `●`, где установленная версия старее
последней.
