# Текущий каталог оболочки для терминала (OSC 7)

`dot_bashrc` печатает после каждой команды последовательность OSC 7 с текущим
каталогом. herdr по ней пересчитывает символ, ветку и состояние git workspace
по событию; foot и kitty берут из неё каталог для новых окон.

- Настройка: функция `__osc7_cwd` в `dot_bashrc`, подключена к `PROMPT_COMMAND`
  (ble.sh выполняет `PROMPT_COMMAND` перед каждым приглашением). Только
  интерактивная оболочка и `$TERM` не `dumb` и не `linux`.
- Хост в URI пустой (`file:///путь`): herdr отвергает URI с именем хоста. Путь
  кодируется по RFC 3986 встроенными командами bash, без подпроцессов; herdr
  раскодирует `%XX`.
- Действует в новых оболочках; уже запущенные оболочки каталог не сообщают.
- Проверка: `printf 'cd /tmp\nexit\n' | script -qec 'bash -i' /dev/null | cat -v`
  содержит `^[]7;file:///tmp^G`; в herdr `herdr pane get <панель>` показывает
  новый `cwd` после смены каталога.
