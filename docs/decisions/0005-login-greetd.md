# 0005. Вход в сессию — greetd с tuigreet

Дата: 2026-09-17. Статус: принято, выполнено.

## Контекст

LightDM со slick-greeter был последним, кому в системе нужен был Xorg:
экран входа рисовал X-сервер, и ради него жили `xorg-server`, `xorg-xrdb`
и `xorg-xmodmap`. Сама сессия к этому времени давно работала под Wayland,
Openbox был удалён. Пользователь потребовал убрать X11 из системы целиком,
оставив только Xwayland для Steam и Wine.

Вход без пароля при загрузке обеспечивала группа `nopasswdlogin`, а выбор
сессии запоминался в `~/.dmrc`.

## Решение

Экран входа — greetd (0.10.3) с текстовым greeter tuigreet (0.11.1)
на виртуальной консоли 1, без X-сервера и без композитора. Сессия
запускается записью `hyprland.desktop` из пакета (`/usr/bin/start-hyprland`),
выбора сессии в greeter нет. При загрузке сессия поднимается без пароля
по разделу `[initial_session]`, после выхода tuigreet спрашивает пароль.

Конфиг `/etc/greetd/config.toml` хранится в репозитории как
`system/greetd/config.toml`; chezmoi каталог `system/` не применяет,
в `/etc` файлы кладёт сценарий `system/greetd/migrate.sh` с правами root.

Следствие, о котором надо помнить: greetd запускает сессию без
login-оболочки и читает только `~/.profile`, поэтому `PATH` сессии
(в том числе shims mise) задают `~/.profile` и `hl.env` в `hyprland.lua`,
а `.bashrc` на сессию не влияет; `XDG_SESSION_TYPE=wayland` тоже выставляет
`hyprland.lua`, greetd этой переменной не задаёт.

Требование — спецификация `hyprland-session`, «Запуск сессии»; разбор
решений и рисков —
`../../openspec/changes/archive/2026-09-17-greetd-login/design.md`.

## Рассмотренные варианты

**LightDM со slick-greeter (прежний вход).** Отвергнут: ради экрана входа
в системе оставался Xorg. Удалён 2026-09-17 после проверки нового входа.

**uwsm и запись `hyprland-uwsm.desktop`.** Отвергнуты (Non-Goals изменения):
переход на uwsm в объём не входил, а список сессий в greeter давал бы
возможность выбрать uwsm по ошибке — поэтому tuigreet запускает одну
команду.

**Графический экран входа: ReGreet, SDDM.** Отвергнуты (Non-Goals
изменения): единственная сессия в системе одна, выбирать в greeter нечего,
а графический greeter добавляет зависимости.

**Вход без пароля через группу `nopasswdlogin`.** Заменён разделом
`[initial_session]`: с PAM greetd группа не связана и действия
не оказывает.

## Условия пересмотра

- В системе появилась вторая сессия: тогда tuigreet нужен список сессий
  (`--sessions`), и решение D1 изменения пересматривается.
- Понадобился пароль и при загрузке: раздел `[initial_session]` удаляется
  одной правкой, остальное не меняется.
- Вход через tuigreet перестал работать после обновления: возврат
  на LightDM уже невозможен, пакет удалён, поэтому починка идёт в greetd
  либо выбирается другой менеджер входа без Xorg.
