# 0011. Запасной профиль сети — соединение `axata-full` и файл профиля

Дата: 2026-11-21. Статус: принято.

## Решение

В условиях, когда основной профиль сети станции (запись
[`0009`](0009-amneziawg-split-by-destination.md)) зависит от подписки
Amnezia и при её отказе станция остаётся без выхода к внешним сервисам,
а OpenVPN `axata` без `ipv4.never-default` принимает от сервера
`redirect-gateway` и пропускает весь трафик через корпоративную сеть,
учитывая, что переход нужен только по решению пользователя и должен
переживать перезагрузку, выбран второй, запасной профиль «всё через axata»:
отдельное соединение NetworkManager `axata-full` (копия `axata` без
`ipv4.never-default`), выбор профиля одной строкой `main` или `backup`
в файле `/etc/amnezia/profile`, по которому юниты загрузки выбирают туннели,
и переход сценарием root `net-profile` с проверкой и откатом из меню
значков туннелей панели без пароля, чтобы оба профиля оставались
неизменными, а выбор хранился в одном месте, ценой двух копий учётных
данных OpenVPN (после правки `axata` копия пересоздаётся
`system/tunnels/install.sh profile`), видимости имён вне зон `ru`, `by`,
`su`, `рф` администратору корпоративной сети и выхода в интернет с адреса
в Белоруссии при запасном профиле.

Устройство и порядок работы — [`../amnezia-split-tunnel.md`](../amnezia-split-tunnel.md),
раздел «Профили сети»; поведение — спецификация network-profiles,
обоснование шагов — `design.md` изменения OpenSpec tunnel-backup-profile.

## Рассмотренные варианты

- Переключать `ipv4.never-default` у одного соединения `axata` — профиль
  виден только по свойству, а не по имени активного соединения, состояние
  NetworkManager расходится с файлом профиля, сбой на полпути оставляет
  соединение с половиной настроек, а у свойства уже два владельца
  (`amn-switch` и `install.sh revert` в `system/amnezia/`).
- Хранить профиль включением юнитов (`awg-quick@amn0` и отдельный юнит
  для `axata-full`) — два источника правды, расходящиеся при сбое
  на полпути; панели пришлось бы читать состояние юнитов вместо файла,
  каталог которого она уже отслеживает.
- Автоматический переход по потере связи `amn0` — отвергнут
  пользователем: переход только вручную.

## Пересмотр

Если раздельная маршрутизация основного профиля станет возможна без
подписки Amnezia (другой поставщик туннеля) или корпоративная сеть
перестанет пропускать внешний трафик.
