# 0010. Подсказка клавиш по контексту — плагин herdr с панелью split

Дата: 2026-11-08. Статус: принято.

## Решение

В условиях, когда горячие клавиши оболочки bash с ble.sh и запущенных в
терминале программ (yazi, Neovim, fzf, atuin, television) нужно видеть
рядом с работой и меняющимся по режиму, учитывая, что всё это живёт
внутри панели herdr, а клавиши композитора уже показывает панель
Quickshell (qs-keys-help), выбран плагин herdr `quiet-lab.keys-help`,
который по клавише Ctrl+Alt+Shift+/ делит панель и открывает внизу
просмотрщик таблицы клавиш контекста; чтобы терминал передавал
модификаторы на пунктуации, в wezterm включён протокол клавиатуры kitty
(`enable_kitty_keyboard = true`), а рамки herdr оставлены только
разделителями (`pane_outer_borders = false`, `pane_gaps = false`); ценой
сборки плагина на Rust при `chezmoi apply`, зависимости от API плагинов
форка herdr и проверки привязок, на которые влияет протокол kitty
(`ctrl+alt+r` herdr, Alt-привязки `~/.blerc`, Esc и стрелки в vi-режиме
ble.sh, клавиши Neovim в панели `claude-input`).

Устройство — [`../keys-help.md`](../keys-help.md), поведение —
спецификация `herdr-keys-help`.

## Рассмотренные варианты

**Панель Quickshell.** Отвергнут: спецификация `qs-keys-help` показывает
только цепочки клавиш композитора и не знает панели терминала и её
переднего плана; она остаётся для клавиш композитора.

**Вывод в информационной области ble.sh.** Отвергнут пользователем;
причина в источниках не записана.

**`pane split` с `pane run` вместо плагина.** Отвергнут: панель без
плагина-владельца, и действие `toggle` не может найти её для закрытия.

**Рамки herdr вокруг панелей.** Отвергнут пользователем: рамки только
разделителями.

## Условия пересмотра

Запись пересматривается, если herdr начнёт сообщать клавиши и режим
переднего плана сам, если протокол kitty в wezterm сломает привязки,
которые не удаётся поправить в конфигах, или если форк herdr перестанет
поддерживать плагины с панелями split.
