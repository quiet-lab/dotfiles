# Записи о решениях

Здесь записано, что выбрано для рабочего окружения, какие варианты
отвергнуты и при каких условиях выбор пересматривается: композитор,
оболочка панели, способ расстановки окон, место хранения привязок клавиш,
менеджер входа, параметры драйвера видеокарты, программа запроса пароля
для sudo.

Спецификации OpenSpec (`../../openspec/specs/`) описывают проверяемое
поведение: как ведут себя панель, демон workspaced и сессия Hyprland
и по каким сценариям это проверяется. Записи здесь описывают выбор,
поведением не являющийся, — он не проверяется сценарием, но объясняет,
почему поведение устроено именно так.

## Правила

- Одна запись — один файл `NNNN-тема-латиницей.md` с порядковым номером,
  датой и статусом в шапке.
- Запись не переписывается задним числом. Если решение изменилось,
  добавляется новая запись со ссылкой на прежнюю, а в прежней статус
  меняется на «отменено записью NNNN».
- Дата — дата принятия решения, а не дата, когда о нём написали. Если
  точную дату установить нельзя, ставится «не позднее <дата>».
- Причина отказа от варианта пишется только та, которая есть в источниках
  (архив `../../openspec/changes/archive/`, история git). Если причина
  нигде не записана, так и указывается — придумывать её задним числом
  нельзя.

Вопросы, по которым решение принять пока нельзя, лежат в соседнем каталоге
[`../open-questions/`](../open-questions/README.md). Когда такой вопрос
решается, его содержание переезжает сюда, а файл вопроса удаляется.
