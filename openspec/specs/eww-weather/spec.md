# eww-weather Specification

## Purpose

Плитка weather-tile: текущая погода и прогноз на 3 дня по частям суток из wttr.in, с цветной подсветкой глифов по коду погоды WWO и оффлайн-фолбэком. Реализация — `widgets/weather/scripts/weather`, вывод — yuck-литерал для переменной `dash-weather` (poll 30 минут).

## Requirements

### Requirement: Источник данных
Данные MUST запрашиваться у `https://wttr.in/<CITY>?format=j1` (`curl -sf --max-time 10`). Пустая переменная `CITY` в скрипте означает автоопределение города по IP.

#### Scenario: Указанный город
- **WHEN** в скрипте задано `CITY="Minsk"`
- **THEN** запрос идёт к wttr.in/Minsk, город берётся из ответа (nearest_area)

### Requirement: Текущая погода
Содержимое плитки MUST быть выровнено по сетке календаря плитки часов: видимая часть текста начинается в 27px от левой рамки и заканчивается в 28px от правой, как шапки плитки часов (поля строк 14px слева, 18px справа у сводки и 23px у строк прогноза, чей последний столбец центрируется в ячейке), снизу отступ 4px, чтобы последняя строка отстояла от рамки как первая от верхней; высота плитки 215px. Первая строка плитки MUST показывать: глиф по weatherCode, температуру `${temp_C}°` полужирным 30.8px цвета рамки (тот же шрифт и цвет, что у времени в плитке часов), название города 21.84px справа цвета рамки на 30% темнее (как дата в плитке часов, `mix($yellow, #000, 70%)`). Глиф и класс цвета определяются таблицей WWO-кодов: ясно 113; малооблачно 116; пасмурно 119/122; туман 143/248/260; дождь — список кодов осадков; снег — список снежных кодов; гроза 200/386/389/392/395; прочее → `w-unknown`.

Цвета классов: w-clear #FFD75E, w-partly #FFC66D, w-overcast #C0CAF5, w-fog #89DDFF, w-rain #74A8FF, w-snow #CBEDFF, w-storm #BB9AF7, w-unknown — серый.

#### Scenario: Гроза
- **WHEN** weatherCode = 200
- **THEN** глиф грозы окрашен классом w-storm (#BB9AF7)

### Requirement: Прогноз на 3 дня
Для каждого из трёх дней MUST выводиться строка: двухбуквенное имя дня недели (ru_RU, первая буква заглавная) и четыре части суток — ночь 0–6, утро 6–12, день 12–18, вечер 18–24. Для части: средняя температура hourly-записей периода (округлённая) + глиф/цвет по weatherCode первой записи периода. Шапка прогноза — четыре неизменных глифа частей суток. Имена дней недели и глифы частей суток в шапке прогноза MUST быть ярко-зелёными, как иероглифы на обоях (`$wall-green`), имя дня — полужирным; температуры частей суток MUST быть цвета рамки (`$yellow`), а глиф ясной погоды (`w-clear`, `$w-clear`) и в сводке, и рядом с ними — чистого жёлтого цвета #FFFF00, глиф пасмурной погоды (`w-overcast`, `$w-overcast`) — нейтрального серого #A0A0A0, глиф дождя (`w-rain`, `$w-rain`) — ярко-синего #0080FF, глиф снега (`w-snow`, `$w-snow`) — белого #FFFFFF, глиф тумана (`w-fog`, `$w-fog`) — светло-серого #D0D0D0.

#### Scenario: Часть суток без записей
- **WHEN** в периоде нет hourly-записей
- **THEN** часть пропускается без ошибки формирования

### Requirement: Оффлайн-фолбэк
Каждый успешный ответ MUST атомарно сохраняться в `/tmp/eww-weather.yuck` (запись во временный файл + mv). При недоступности сети или пустом ответе плитка MUST показать последний сохранённый снимок; если кэша нет — метку «нет данных» приглушённым цветом.

#### Scenario: Обрыв сети
- **WHEN** curl завершился ошибкой при наличии кэша
- **THEN** пользователь видит последнюю удачную погоду, а не пустую плитку
