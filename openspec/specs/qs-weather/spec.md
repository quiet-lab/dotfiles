# qs-weather Specification

## Purpose

Плитка погоды панели Quickshell: текущая сводка с городом и прогноз на 3 дня по частям суток из wttr.in, глифы с цветной подсветкой по коду погоды WWO, обновление раз в 30 минут и показ последнего снимка из кэша при обрыве связи. Данные поставляет скрипт панели в формате JSON.

## Requirements

### Requirement: Источник данных
Данные погоды MUST поставлять скрипт `dot_config/quickshell/panel/scripts/weather` (в `$HOME` — `~/.config/quickshell/panel/scripts/weather`), запрашивающий `https://wttr.in/<CITY>?format=j1` командой `curl -sf --max-time 10`. Пустая переменная `CITY` в скрипте MUST означать автоопределение города по IP-адресу; непустая — запрос к `wttr.in/<CITY>`. Название города MUST браться из ответа wttr.in (поле `nearest_area`), а не из переменной. Панель MUST запускать скрипт при старте и далее раз в 30 минут.

#### Scenario: Указанный город
- **WHEN** в скрипте задано `CITY="Minsk"`
- **THEN** запрос идёт к `wttr.in/Minsk`, а в сводке показано название города из ответа wttr.in

#### Scenario: Периодическое обновление
- **WHEN** панель работает без перезапуска дольше 30 минут
- **THEN** скрипт погоды выполнен повторно, и сводка отражает свежий ответ wttr.in

### Requirement: Формат данных скрипта
Скрипт MUST выводить на стандартный вывод один объект JSON, а не разметку виджета. Объект MUST содержать: название города, текущую температуру в градусах Цельсия, код погоды WWO текущего состояния и список ровно из трёх дней прогноза. Каждый день MUST содержать двухбуквенное имя дня недели и четыре части суток в порядке ночь, утро, день, вечер; каждая часть — либо округлённую среднюю температуру и код погоды WWO, либо явную отметку отсутствия данных. Соответствие кода погоды глифу и цвету MUST определяться на стороне панели по коду, поэтому глифы и имена цветов в JSON MUST NOT передаваться. Вывод скрипта MUST разбираться стандартным разборщиком JSON без предварительной обработки.

#### Scenario: Ответ wttr.in получен
- **WHEN** wttr.in вернул корректный ответ формата j1
- **THEN** скрипт печатает один объект JSON с городом, температурой, кодом погоды и тремя днями по четыре части суток, и панель показывает сводку и прогноз без ошибок разбора

#### Scenario: Часть суток без записей
- **WHEN** в почасовом прогнозе дня нет записей за один из периодов
- **THEN** соответствующая часть суток помечена как отсутствующая, остальные части дня выведены, а скрипт завершается без ошибки

### Requirement: Текущая погода
Первая строка плитки MUST показывать глиф по коду погоды WWO, температуру `<temp_C>°` полужирным шрифтом 30.8px цвета рамки плитки (тот же шрифт и цвет, что у времени в плитке часов) и справа название города шрифтом 21.84px цветом рамки на 30% темнее (как дата в плитке часов). Содержимое плитки MUST быть выровнено по сетке календаря плитки часов: видимая часть текста начинается в 27px от левой рамки и заканчивается в 28px от правой; снизу отступ 4px, чтобы последняя строка прогноза отстояла от рамки так же, как первая от верхней; высота плитки 215px. Глиф и цвет MUST определяться таблицей кодов WWO: ясно — 113; малооблачно — 116; пасмурно — 119, 122; туман — 143, 248, 260; дождь — 176, 263, 266, 281, 284, 293, 296, 299, 302, 305, 308, 311, 314, 350, 353, 356, 359, 374, 377; снег — 179, 182, 185, 227, 230, 317, 320, 323, 326, 329, 332, 335, 338, 362, 365, 368, 371; гроза — 200, 386, 389, 392, 395; любой другой код — глиф «неизвестно» приглушённым серым цветом.

Цвета подсветки: ясно #FFFF00, малооблачно #FFC66D, пасмурно #A0A0A0, туман #D0D0D0, дождь #0080FF, снег #FFFFFF, гроза #A020F0. Цвета одинаковы для глифа сводки и глифов прогноза.

#### Scenario: Гроза
- **WHEN** код погоды текущего состояния равен 200
- **THEN** в сводке показан глиф грозы фиолетовым цветом #A020F0

#### Scenario: Неизвестный код
- **WHEN** wttr.in вернул код погоды, которого нет в таблице
- **THEN** в сводке показан глиф «неизвестно» приглушённым серым цветом, температура и город выведены как обычно

### Requirement: Прогноз на 3 дня
Под сводкой MUST располагаться шапка прогноза из четырёх неизменных глифов частей суток (ночь, утро, день, вечер) и три строки — по одной на день. Строка дня MUST начинаться с двухбуквенного имени дня недели по локали ru_RU с заглавной первой буквой и содержать четыре части суток: ночь 0–6, утро 6–12, день 12–18, вечер 18–24. Для части MUST выводиться округлённая средняя температура почасовых записей периода со знаком градуса и глиф по коду погоды первой записи периода; часть без данных MUST пропускаться. Имена дней недели и глифы шапки MUST быть белыми (#FFFFFF), имя дня — полужирным; температуры частей суток MUST быть цвета рамки плитки; глифы условий MUST окрашиваться по той же таблице цветов, что и глиф сводки.

#### Scenario: Строка дня
- **WHEN** для дня получены почасовые записи во всех четырёх периодах
- **THEN** строка показывает белое полужирное имя дня и четыре пары «температура цвета рамки, глиф условия в цвете по коду погоды»

#### Scenario: Локаль
- **WHEN** прогноз построен для даты, приходящейся на понедельник
- **THEN** имя дня показано как «Пн»

### Requirement: Оффлайн-фолбэк
Каждый успешный ответ MUST сохраняться скриптом в кэш `$XDG_CACHE_HOME/quickshell-weather.json` (при незаданной переменной — `~/.cache/quickshell-weather.json`) атомарно: запись во временный файл и переименование. Кэш в `/tmp` MUST NOT использоваться, чтобы снимок переживал перезагрузку. При ошибке curl, пустом ответе или ответе без температуры скрипт MUST вывести содержимое кэша, если он есть; если кэша нет — панель MUST показать метку «нет данных» приглушённым цветом. До первого ответа скрипта плитка MUST показывать заполнитель «…» приглушённым цветом, а не пустую область.

#### Scenario: Обрыв связи
- **WHEN** curl завершился ошибкой, а кэш существует
- **THEN** плитка показывает последнюю удачную сводку и прогноз, а не пустую плитку

#### Scenario: Нет кэша
- **WHEN** сеть недоступна при первом запуске панели, и файла кэша нет
- **THEN** плитка показывает метку «нет данных» приглушённым цветом

#### Scenario: Снимок после перезагрузки
- **WHEN** система перезагружена и панель запущена без доступа к сети
- **THEN** плитка показывает сводку из кэша, сохранённого до перезагрузки
