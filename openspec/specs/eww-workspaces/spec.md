# eww-workspaces Specification

## Purpose

Модуль рабочих столов Openbox: вертикальная колонка плиток столов с окнами активного стола. Реализация — `scripts/workspace` (deflisten `workspace`), иконки через общий резолвер `scripts/appicon`.

## Requirements

### Requirement: Реактивное обновление
Скрипт MUST вывести начальное состояние и перерисовываться на каждое событие `xprop -root -spy _NET_CURRENT_DESKTOP _NET_CLIENT_LIST`. Число столов — `xdotool get_num_desktops`, фолбэк 8; текущий стол — `xdotool get_desktop`, фолбэк 0.

#### Scenario: Переключение стола
- **WHEN** пользователь переходит на другой рабочий стол
- **THEN** колонка перестраивается: разворачивается новый активный, прежний сворачивается до иконок

### Requirement: Активный стол
Плитка активного стола MUST иметь класс `ws ws-fo` (рамка cyan), заголовок «СТОЛ N» и строку-кнопку на каждое окно: полноцветная иконка 22×22 (`ws-win-img`) либо глиф-фолбэк, название программы. Клик по строке MUST выполнять `xdotool set_desktop <стол>` + `xdotool windowactivate <id>`. Свёрнутые окна получают класс `ws-min` (приглушённые цвета).

#### Scenario: Клик по окну другого стола невозможен
- **WHEN** пользователь кликает по строке окна
- **THEN** активируется именно это окно на его столе

### Requirement: Занятые неактивные столы
Стол с окнами вне фокуса MUST показывать номер и ряд полноцветных иконок приложений 20×20 без названий; клик переключает на этот стол (`xdotool set_desktop`). Пустой стол — только номер в кнопке.

#### Scenario: Иконки занятого стола
- **WHEN** на столе открыты firefox и wezterm
- **THEN** плитка показывает «2 [иконка firefox][иконка wezterm]»

### Requirement: Исключения окон
Из списка MUST исключаться sticky-окна (десктоп 4294967295) — панели, трей, окна самого eww. Окна без читаемого десктопа пропускаются.

#### Scenario: Трей не попадает в списки
- **WHEN** запущен trayer/sticky-виджет
- **THEN** ни одна плитка его не показывает

### Requirement: Соответствие WM_CLASS
Таблицы соответствия MUST покрывать известные классы (firefox/Navigator, Chromium/Google-chrome, Yandex-browser*, Wezterm/org.wezfurlong.wezterm, терминалы, Neovide/nvim, TelegramDesktop, pavucontrol, nm-connection-editor, Thunar, PCManFM, Code/code-oss): имя иконки-кандидата, человекочитаемое название строки. Неизвестный класс → кандидаты из нижнего регистра класса и его последнего компонента; название — последний компонент после точки.

Иконки разрешаются общим резолвером appicon; при неудаче используется Nerd Font глиф-фолбэк.

#### Scenario: Браузер
- **WHEN** WM_CLASS окна = «Navigator»
- **THEN** строка называется «Firefox» с иконкой firefox

### Requirement: Экранирование вывода
Названия окон MUST экранироваться для yuck-литерала: `\` → `\\`, `"` → `\"`, вертикальная черта `|` заменяется на `∕` (разделитель записей внутри скрипта).

#### Scenario: Кавычки в заголовке окна
- **WHEN** окно имеет заголовок с символом `"`, попавший в таблицу имён
- **THEN** сгенерированный yuck остаётся синтаксически корректным
