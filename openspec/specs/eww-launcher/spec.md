# eww-launcher Specification

## Purpose

Лаунчер приложений внутри дашборда: поиск по названию и сетка полноцветных иконок из .desktop-записей. Реализации — `scripts/apps-list` (генерация сетки), `scripts/apps-update` (обработка ввода), плитка launcher-tile.

## Requirements

### Requirement: Источники записей
Записи MUST собираться из `~/.local/share/applications` и `/usr/share/applications`. Исключаются: NoDisplay=true, Hidden=true, Type отличное от Application (пустой Type допустим). Дедупликация по id файла — пользовательский каталог приоритетен.

Имя записи: `Name[ru_RU]` → `Name[ru]` → `Name` → id файла как фолбэк. Сортировка по имени в локали ru_RU без учёта регистра.

#### Scenario: Русское имя приоритетно
- **WHEN** запись имеет Name[ru_RU] и Name
- **THEN** тултип кнопки показывает русское название

#### Scenario: Дубль приложения
- **WHEN** org.example.desktop существует в обоих каталогах
- **THEN** в сетке ровно одна кнопка — из пользовательского каталога

### Requirement: Фильтр по подстроке
Фильтрация MUST идти по имени без учёта регистра (grep -F -i, локаль ru_RU). Пустой результат — пустой контейнер без ошибки.

Поле поиска (`input`) по каждому изменению текста вызывает `scripts/apps-update '{}'`, который сохраняет запрос в переменную `apps-query` и перегенерирует сетку.

Периодическое обновление сетки (poll 60s) MUST читать активный запрос через `eww get apps-query` — фильтр не сбрасывается между обновлениями.

#### Scenario: Фильтр переживает refresh
- **WHEN** пользователь ввёл «бра» и прошло 60 секунд
- **THEN** сетка показывает только совпадения с «бра»

#### Scenario: Нет совпадений
- **WHEN** введена бессмысленная строка
- **THEN** область сетки пуста, eww не логирует ошибок

### Requirement: Сетка иконок
Сетка MUST строиться рядами по 7 ячеек (шаг 38px, зазор 5px); видимой является область высотой 124px = три ряда, остальное доступно вертикальной прокруткой (scroll с hscroll false; полоса прокрутки скрыта, колесо мыши работает).

Иконки: уникальные значения Icon= резолвируются параллельно (xargs -P8) через scripts/appicon; отображение image 32×32. Не разрешившаяся иконка → метка «?» (класс app-btn-fallback). Имя приложения — тултип кнопки.

#### Scenario: Три ряда видно целиком
- **WHEN** приложений больше 21
- **THEN** первые три ряда помещаются в окно, остальные доступны скроллом

### Requirement: Запуск приложений
Клик MUST запускать:
- Terminal=false/отсутствует → `gtk-launch "<id>" &`;
- Terminal=true → `wezterm start -- <Exec без %-кодов> &`.

%-коды полей Exec (`%f`, `%u` и т.п.) вырезаются, хвостовые пробелы обрезаются.

#### Scenario: Консольная утилита
- **WHEN** запись yazi.desktop имеет Terminal=true и Exec=yazi
- **THEN** открывается wezterm с запущенным yazi

#### Scenario: GUI-приложение
- **WHEN** запись firefox.desktop без Terminal
- **THEN** выполняется gtk-launch org.mozilla.firefox (id записи)
