## ADDED Requirements

### Requirement: Окно подсказки клавиш
Панель Quickshell MUST иметь окно подсказки клавиш — окно layer-shell на слое Overlay во весь экран DP-2, которое не резервирует зону и не сдвигает окна. Экран под окном MUST затемняться, а перечень MUST рисоваться карточкой по центру экрана в оформлении плиток панели: заливка и рамка плиток, шрифт темы. Карточка MUST содержать заголовок «ГОРЯЧИЕ КЛАВИШИ» с напоминанием, как закрыть окно, и группы перечня в три колонки: название группы заголовком, под ним строки «подпись цепочки — описание». Группы MUST идти в порядке перечня и раскладываться по колонкам по порядку, так чтобы колонки были близки по числу строк. Окно MUST NOT закрываться само по истечении времени.

#### Scenario: Вид перечня
- **WHEN** окно подсказки открыто при конфиге сессии
- **THEN** по центру экрана видна карточка с группами «Workspace», «Столы», «Приложения», «Окна», «Уведомления», «Звук и яркость», «Снимки экрана», «Раскладка», «Сессия и прочее» в три колонки, в группе «Окна» есть строка «Super+Delete — Закрыть окно», а `hyprctl layers` содержит слой `keys-help` размером с экран

### Requirement: Источник перечня
Перечень MUST читаться командой `~/.local/bin/workspaced keys --json` (спецификация ws-config, «Перечень клавиш для подсказки») при каждом открытии окна; панель MUST NOT опрашивать команду по времени и MUST NOT хранить перечень в собственном файле. Пока команда выполняется, окно MUST показывать прежний перечень, а при первом открытии — надпись «Загрузка…». Если команда завершилась ненулевым кодом или её вывод не разобран как JSON, окно MUST показывать текст ошибки вместо перечня.

#### Scenario: Правка конфига видна при следующем открытии
- **WHEN** в конфиг демона добавлена запись `[[binds]]` с `desc = "Проба"`, после чего окно подсказки открыто
- **THEN** в окне есть строка с описанием «Проба», перезапуск панели не нужен

#### Scenario: Ошибка конфига
- **WHEN** конфиг демона содержит привязку на зарезервированное сочетание и окно подсказки открыто
- **THEN** окно показывает текст ошибки `workspaced keys --json`, называющий запись и сочетание

### Requirement: Открытие и закрытие подсказки
Панель MUST объявлять IPC-цель `keys` с функциями `toggle` (показать скрытое окно или скрыть показанное), `open`, `close` и `state` (строка «shown» или «hidden» с числом групп и строк перечня). Привязка Shift+Super+/ (спецификация hyprland-binds) MUST вызывать `qs -c panel ipc call keys toggle`. Показанное окно MUST закрываться повторным Shift+Super+/, клавишей Escape и кликом мимо карточки; клик по карточке MUST NOT закрывать окно. Пока окно показано, его слой MUST держать клавиатуру монопольно; скрытое окно MUST NOT держать клавиатуру и MUST NOT принимать ввод, и фокус MUST возвращаться окну, у которого был до показа.

#### Scenario: Повторное нажатие скрывает окно
- **WHEN** выполнена `qs -c panel ipc call keys toggle`, затем ещё раз
- **THEN** после первого вызова `qs -c panel ipc call keys state` начинается с «shown» и слой `keys-help` есть в `hyprctl layers`, после второго — «hidden», слоя нет

#### Scenario: Закрытие клавишей и кликом
- **WHEN** окно подсказки открыто Shift+Super+/ и нажат Escape; окно открыто снова и выполнен клик по затемнённой части экрана
- **THEN** оба раза окно скрывается, а ввод с клавиатуры снова получает окно, которое было активным до показа
