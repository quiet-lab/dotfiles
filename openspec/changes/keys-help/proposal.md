## Why

Пользователь 23.09.2026: «Shift+Super+/ должен вызывать панель со списком
цепочек горячих клавиш. Они должны быть сгруппированы по назначению.
Повторное нажатие должно скрывать панель подсказок.»

Привязок в сессии около девяноста, и все они записаны в конфиге демона
workspaced. Увидеть их можно только командой `workspaced keys --list`
в терминале: таблица без описаний, отсортированная по разделам конфига,
а не по назначению.

## What Changes

- Демон: команда `workspaced keys --json` печатает перечень привязок,
  сгруппированный по назначению (Workspace, Столы, Приложения, Окна,
  Уведомления, Звук и яркость, Снимки экрана, Раскладка, Сессия и прочее).
  У каждой строки — подпись цепочки для человека («Shift+Super+/»),
  описание, действие и источник. Серия `range` выводится одной строкой
  («Super+1…8»), зарезервированные сочетания `[keys]` — в группе «Раскладка».
- Конфиг демона: у записи `[[binds]]` появляются необязательные поля `desc`
  (описание) и `group` (группа), у раздела `[keys]` — таблица `reserved_desc`
  с описаниями зарезервированных сочетаний. Без них описание и группа
  выводятся из действия. Существующим записям `exec`, `dispatch` и `lua`
  заданы описания, лаунчеру и Alt+Tab — группы.
- Новая привязка Shift+Super+/ (`SUPER+SHIFT+slash`) вызывает
  `qs -c panel ipc call keys toggle`.
- Панель Quickshell: окно подсказки клавиш по центру экрана — карточка
  в оформлении плиток с группами в три колонки, строка «цепочка —
  описание». Повторное Shift+Super+/, Escape и клик мимо карточки закрывают
  окно. Перечень читается командой `workspaced keys --json` при каждом
  открытии окна.

## Capabilities

### New Capabilities

- `qs-keys-help`: окно подсказки клавиш панели — содержание, группы,
  открытие и закрытие, IPC-цель `keys`.

### Modified Capabilities

- `hyprland-binds`: требование «Раскладка клавиш сессии» — строка
  Shift+Super+/.
- `ws-config`: требование «Цепочки клавиш и привязки» — поля `desc`
  и `group`, таблица `reserved_desc`; новое требование «Перечень клавиш
  для подсказки» — команда `workspaced keys --json`.
