## ADDED Requirements

### Requirement: Окно буфера ввода переносит строки визуально
Окно, показывающее буфер `claude://input` или `claude://dialog`, MUST переносить длинные строки по словам визуально (`wrap`, `linebreak`, `breakindent`), настройка MUST ставиться на окно при каждом показе буфера, а не глобально, и MUST NOT затрагивать окна других буферов. Содержимое буфера и текст, отправляемый в строку ввода Claude Code, MUST NOT содержать вставленных символов переноса.

#### Scenario: Длинная строка в буфере ввода
- **WHEN** в `claude://input` набрана строка длиннее ширины окна
- **THEN** окно показывает её перенесённой по словам, в буфере она остаётся одной строкой, в строку ввода Claude Code текст уходит без переносов

#### Scenario: Длинная строка в буфере диалога
- **WHEN** в `claude://dialog` набрана строка длиннее ширины окна
- **THEN** окно показывает её перенесённой по словам, в буфере она остаётся одной строкой

#### Scenario: Соседний буфер
- **WHEN** в том же Neovim открыто окно другого буфера
- **THEN** его опции переноса не меняются
