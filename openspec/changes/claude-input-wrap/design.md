# Design: Перенос строк в окне буфера ввода

## Решение

Перенос задаётся оконными опциями (`wrap`, `linebreak` — перенос по словам,
`breakindent`), а не вставкой символов переноса: текст буфера и то, что уходит
в строку ввода Claude Code, остаются прежними.

Опции ставит автокоманда `BufWinEnter` на буфере (при каждом показе в окне),
а `BufWinLeave` возвращает прежние значения окна: соседние буферы того же
Neovim, показанные в этом окне позже, настройку не наследуют. Глобальные
опции не меняются.
