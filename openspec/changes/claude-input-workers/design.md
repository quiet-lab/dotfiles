# Design: Панель ввода у исполнителей duty

## Решение

Пользователь 6 ноября 2026 решил: панель ввода открывается у всех сессий
Claude Code в herdr, включая исполнителей duty; исключение субагентов
(`agent_id`) остаётся. Причина прежнего исключения нигде не записана
(коммит `7bc58e2` без обоснования).

## Что проверялось

- `close` по `SessionEnd` закрывает панель буфера до того, как агент worker
  закрывает свою панель (`herdr pane close --current`): хук `SessionEnd`
  выполняется при завершении сессии, а панель закрывается последним действием
  после уведомления; итог живой проверки — в `tasks.md`, п. 3.1.
- `dispatch.sh close` закрывает вкладки и workspace целиком
  (`herdr workspace close`), поэтому панель nvim в том же workspace сиротой
  не остаётся; файл соответствия в `~/.local/state/claude-input/` может
  остаться, но `open` проверяет живость записанной панели.
