## Decisions

- **Источник символа — векторный логотип клиента.** В
  `client/images/amneziaLogo.svg` репозитория amnezia-vpn/amnezia-client
  (ветвь `dev`, GPL-3.0) 76 путей: 40 — надпись «AMNEZIA» кистью
  (y 71–110), 9 — «YOUR OWN VPN» (y 119–128), 27 — символ (x 43–118,
  y 3.5–76; пути 41–67). Границы символа определены по ограничивающим
  прямоугольникам путей. Растровый значок приложения
  (`AmneziaVPN.png`) — тот же символ в круге; круг не нужен, а растр не
  перекрашивается. Вариант кистью с Freepik при 20 px неразличим.
- **Один путь вместо 27.** Пути символа объединены в одну строку
  `PathSvg` с правилом заливки nonzero (в символе нет evenodd): один
  ShapePath, один цвет. Путь лежит в `icons/amnezia.js` (`.pragma
  library`), чтобы 18 КБ координат не загромождали `Tray.qml`;
  `amnezia-symbol.svg` — тот же путь для просмотра.
- **Штрих цвета заливки в 2 единицы логотипа (около 0,5 px).** Без
  штриха между соседними путями видны стыки, а при 20 px символ легче
  глифа `axata`. Штрих подобран по снимкам при 0,6, 2, 3 и 4 единицах:
  при 2 вес совпадает с глифом `axata`, просветы в букве A остаются.
- **`Theme.brightGreen` = #98D048** — ярчайший оттенок молний обоев
  `mechanical/okita-souji` по гистограмме. Отдельный токен, а не замена
  `Theme.green`: остальные плитки сохраняют нынешний цвет.
