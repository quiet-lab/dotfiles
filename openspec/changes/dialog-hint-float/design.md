## Context

Панель ввода — 13 строк; виртуальные строки подсказки сдвигают текст ответа.

## Decisions

- Окно: `relative = "win"` к окну диалога, `anchor = "SE"`, `row`/`col` равны высоте и ширине окна диалога, `focusable = false`, `style = "minimal"`, `zindex = 100`, `noautocmd`. Размер — по самой длинной строке и числу строк, но не больше окна диалога (лишнее обрезается, `wrap` выключен).
- Обновление: по каждому экрану диалога (`show_hint`), по `WinResized`/`VimResized` тем же `nvim_win_set_config`.
- Закрытие: при возврате к вводу (`show_input`) и по `BufWipeout`/`BufDelete` буфера диалога.
- Вид — как у which-key (решение пользователя): пресет helix (внизу справа), рамка `rounded`, заголовок в рамке, строки «клавиша → описание» с колонкой клавиш по правому краю. which-key как библиотека не вызывается: его окно живёт только на время ожидания клавиши. Подсветка — группы which-key, при отсутствии (`hlexists`) — запасные `Special`, `Comment`, `Normal`, `Title`, `FloatBorder`, `NormalFloat`; выделенный пункт — `CursorLine`.
- Размер окна ограничен окном диалога за вычетом рамки (по 2).
