## MODIFIED Requirements

### Requirement: Буфер диалога открывается на время диалога
Пока панель Claude Code в статусе `blocked` и её экран — диалог с пунктами выбора, окно панели буфера MUST показывать буфер `claude://dialog` (`buftype=acwrite`, без файла подкачки, пустой при открытии, режим вставки) вместо `claude://input`. Открытый буфер диалога MUST оставаться, пока экран остаётся диалогом, при любом статусе, до `:w` с ответом. После `:w` буфер диалога MUST NOT открываться снова, пока экран совпадает с диалогом, на который ответ отправлен. Переходы MUST происходить по событиям подписки herdr `pane.agent_status_changed` и по правкам буфера диалога, без таймеров.

#### Scenario: Вопрос с вариантами
- **WHEN** в буфере ввода набран текст «черновик», а Claude Code открывает AskUserQuestion
- **THEN** окно панели буфера показывает пустой `claude://dialog` в режиме вставки

#### Scenario: Местный диалог
- **WHEN** открыт выбор модели `/model` (статус `idle`)
- **THEN** буфер диалога не открывается

#### Scenario: Экран отвеченного диалога
- **WHEN** по `:w` ответ отправлен, а экран панели ещё совпадает с отвеченным диалогом
- **THEN** буфер диалога не открывается

### Requirement: Буфер ввода возвращается после диалога
По `:w` в буфере диалога окно панели буфера MUST сразу возвращаться к `claude://input` с прежним содержимым, не дожидаясь смены экрана панели Claude Code; буфер диалога MUST закрываться. Когда экран панели перестаёт быть диалогом без `:w`, окно MUST возвращаться к вводу так же.

#### Scenario: Диалог закрыт
- **WHEN** по `:w` ответ на диалог отправлен
- **THEN** окно панели буфера сразу показывает `claude://input` с текстом «черновик»

### Requirement: Сохранение буфера диалога подтверждает выбор
`:w` в буфере диалога MUST подтверждать выбор клавишей Enter (`pane.send_keys`): в множественном выборе — после перехода стрелками на строку «Submit», иначе — сразу; затем буфер диалога MUST очищаться и закрываться, окно возвращается к вводу. В карточке из нескольких вопросов `:w` MUST переходить к следующему вопросу, а экран следующего вопроса MUST открывать пустой буфер диалога заново; `:w` на вкладке обзора MUST отправлять ответы. `:q` MUST закрывать neovim и панель, как в буфере ввода.

#### Scenario: Карточка из двух вопросов
- **WHEN** в первом вопросе выделен пункт 2 и выполнено `:w`
- **THEN** выбран пункт 2, окно показывает `claude://input`, а по экрану второго вопроса — пустой `claude://dialog`
