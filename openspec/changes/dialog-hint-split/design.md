## Решения

- **Окно разделения вместо плавающего.** Решение пользователя от 2026-11-07, заменяет решение `dialog-hint-float`: подсказка не перекрывает текст диалога. Окно создаётся `nvim_open_win` с `split = "right"` относительно окна диалога, без фокуса.
- **Ширина.** `max(20, floor(W / 5))`, где `W` — сумма ширин окон диалога и подсказки плюс один столбец вертикального разделителя (то есть ширина панели). Окно подсказки получает `winfixwidth`, остаток достаётся диалогу; в узкой панели подсказке ровно 20 столбцов. Пересчёт — по каждому экрану диалога и по `WinResized`/`VimResized` через `nvim_win_set_width`, только если ширина изменилась. Таймеров нет.
- **Заголовок.** В `winbar` окна подсказки («Вопрос k из n», «Обзор ответов», «Диалог»): у окна разделения нет рамки и `title`. Строка winbar занимает одну строку высоты, поэтому под строки клавиш остаётся высота окна минус один; обрезка по высоте прежняя (клавиши внизу, пункты — вокруг выделенного).
- **Обрезка по ширине.** `wrap` выключен: длинные строки обрезаются, а не переносятся.
- **Закрытие.** При возврате к вводу, при `BufWipeout`/`BufDelete` буфера диалога и при отмене; окно ввода снова занимает всю ширину.
