## 4. Манифесты первой очереди (Sonnet)

Во всех манифестах короткие описания (`desc` в `[[describe]]`) — что делает действие, в нескольких словах, по-русски, без имён виджетов и функций; полный текст источника — в `desc_full`; `raw` — исходная строка источника.

- [x] 4.1 `ble.toml`: режимы, регулярное выражение дампа `-P` (строка целиком — в `raw`), короткие описания виджетов по-русски для всех показываемых записей, группы (`history`, `completion`, `edit`, `motion`, …), происхождение (`readline`, `ble`, `fzf`, `atuin`, `tv`, `user`).
- [x] 4.2 `fzf.toml` (man fzf + `{env.FZF_DEFAULT_OPTS}`), `atuin.toml` (`keymap_mode`, `[keys]`), `tv.toml` (`[keybindings]`).
- [x] 4.3 `yazi.toml` и `manifests/data/yazi-keymap-26.9.1.toml` (умолчания yazi 26.9.1 из исходников выпуска), имена слоёв; `desc` из `keymap.toml` — в `desc_full`, короткие описания переформулированы в манифесте.
- [x] 4.4 `nvim.toml` (источник `json` через `--remote-expr`: `desc` привязки — `desc_full` и короткое описание, если оно короче 32 символов, иначе сокращение D7а; `rhs` и файл определения — в `raw`; статическая таблица базовых клавиш vim в `manifests/data/` с короткими описаниями).
