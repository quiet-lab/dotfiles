## MODIFIED Requirements

### Requirement: Раскладка клавиш сессии
Конфиг демона workspaced (`~/.config/workspaced/config.toml`: разделы `[keys]`, цепочки workspace и приложений, записи `[[binds]]`) MUST задавать все привязки сессии; `hyprland.lua` MUST NOT содержать собственных привязок, кроме загрузки кода привязок от демона. Раскладка строится от понятий демона: префикс Super+Tab для действий с workspace, префикс Ctrl+Super+S для сохранения, слой Alt+Super для геометрии окна, слой Ctrl+Super для стола и расстановки, Super+буква для приложений workspace, действий с окном и программ, Shift+Super+буква — собственные клавиши браузеров `surf`:

| Сочетание | Действие |
|---|---|
| Super+Tab w | поднять workspace work на текущем столе (цепочка workspace) |
| Super+Tab s | поднять workspace surf (браузеры из контейнера fedora-box на шаблоне overlay: Яндекс.Браузер по центру, главный, Chrome профиля Default слева, профиля AI.dev2026 справа) на текущем столе |
| Super+Tab Tab | поднять следующий workspace из списка текущего стола |
| Ctrl+Super+S Ctrl+Super+S | записать снимок сессии: команда проходит по всем столам с активным workspace, принимает в них ещё не учтённые окна, обновляет места дополнительных приложений по нынешнему положению окон и пишет `default.toml`; сам по себе снимок не пишется, файл конфига не меняется |
| Ctrl+Super+S Ctrl+Super+W | записать активный workspace в конфиг вместе с его дополнительными приложениями сессии |
| Super+T / C / E | клавиша приложения herdr (wezterm с herdr) / Chromium / neovide: цикл по его окнам в режиме приложения в workspace (собственные клавиши приложений из одного сочетания) |
| Super+S | окно выбора сессии |
| Super+R | лаунчер `rofi -show drun` |
| Super+Delete | закрыть активное окно |
| Super+Backspace | отделить активное окно от активного workspace текущего стола командой демона `detach`: окно выходит из его состава; окно, входящее в другие workspace, уходит к ним, а закрывается только окно, для которого этот workspace был последним |
| Super+B | клавиша `surf` для Google Chrome профиля Default (ключ приложения `chrome` в записи `surf`): в `surf` — цикл по окнам `chrome`, на другом столе — поднять `surf` |
| Super+V | то же для Google Chrome профиля AI.dev2026 (приложение `chrome-ai`) |
| Super+Y | то же для Яндекс.Браузера из контейнера fedora-box (приложение `yandex-browser`) |
| Shift+Super+B / V / Y | собственные клавиши приложений `chrome` / `chrome-ai` / `yandex-browser`: в `surf` — цикл по окнам браузера; на столе с другим активным workspace — перетащить окна браузера в этот workspace, если `surf` запущен (окна становятся общими), или открыть браузер в нём, если нет; на столе без активного workspace — поднять `surf` |
| Super+Insert | меню буфера обмена (история cliphist через rofi, выбранная запись вставляется в буфер) |
| Super+Z | спрятать активное окно в специальный рабочий стол без перехода за ним |
| Super+Shift+Z | показать или скрыть специальный рабочий стол со спрятанными окнами |
| Super+стрелки | перенести фокус на соседнее окно в направлении стрелки |
| Alt+Super+Влево / Вправо | активное окно занимает левую / правую половину рабочей области командой демона `half` с отступом 10 px от краёв и между окнами, тем же, что между плитками панели |
| Alt+Super+Вверх / Вниз | активное окно занимает верхнюю / нижнюю половину рабочей области с теми же отступами |
| Alt+Super+Home / PageDown / End | активное окно в половину ширины и высоты рабочей области в верхнем ряду слева / по центру / справа командой демона `place` с теми же отступами |
| Ctrl+Alt+Super+Z / X / V | то же в нижнем ряду слева / по центру / справа |
| Ctrl+Alt+Super+C | активное окно в половину ширины на всю высоту по центру |
| Alt+Super+PageUp | переключить развёртывание окна командой демона `maximize`: окно занимает рабочую область с отступом 10 px от краёв экрана и панели, тем же, что у половин и плиток панели; повторное нажатие возвращает прежние положение и размер |
| Alt+Super+Enter | активное окно плавающим размером 1920×1080 по центру рабочей области диспетчерами композитора (`window.resize`, `window.center`), без отступов демона |
| Alt+Super+Menu | переключить полноэкранный режим |

| Super+Shift+1…8 | перенести активное окно на стол 1…8 и перейти вслед за ним |

| Alt+Tab, Alt+Shift+Tab | переключить фокус на следующее / предыдущее окно текущего стола с подъёмом окна наверх |
| Super+L | заблокировать сессию командой `loginctl lock-session` |
| Ctrl+Alt+Super+Escape | выход из сессии |
| Print, Ctrl+Print, Shift+Print | скриншот экрана, с обратным отсчётом, области |

Привязка записана именем keysym `SUPER+SHIFT+slash` и срабатывает при любой раскладке: Hyprland сверяет привязки по первой раскладке карты XKB (`us`) |
| Ctrl+Escape, Super+Enter, Shift+Super+Enter, Ctrl+Пробел, Ctrl+Shift+Пробел, Super+Ctrl+Enter, Super+Ctrl+Alt+Enter | уведомления панели Quickshell (`qs -c panel ipc call notifications …`): окно истории, убрать верхнюю карточку с экрана без удаления из истории (`dismissOldest`), выполнить её действие по умолчанию и удалить из истории (`invokeOldest`), пометить просмотренным последнее пришедшее (`close`), пометить просмотренными все (`closeAll`, то же вторым сочетанием), очистить историю целиком (`clear`) |

| XF86MonBrightnessUp / Down | `~/.local/bin/handmade-scripts/change-brightness.sh` с аргументами `+`, `-` |
| XF86AudioPlay / Stop / Prev / Next | playerctl play-pause, stop, previous, next |
| Super+левая кнопка мыши | перемещение окна перетаскиванием |
| Super+правая кнопка мыши | изменение размера перетаскиванием |

Сочетания Super+Shift+стрелки MUST оставаться свободными. Рабочая область — площадь монитора за вычетом зон, зарезервированных слоями (панелью).

#### Scenario: Префикс workspace
- **WHEN** нажато Super+Tab, затем w
- **THEN** на текущем столе поднимается workspace work, подкарта закрывается; `hyprctl binds` содержит подкарту, открываемую Super+Tab, и не содержит одиночного действия на Super+Tab

#### Scenario: Следующий workspace
- **WHEN** на столе два workspace и нажато Super+Tab, затем Tab
- **THEN** поднимается следующий workspace из списка стола

#### Scenario: Префикс сохранения
- **WHEN** нажато Ctrl+Super+S, затем Ctrl+Super+S
- **THEN** снимок сессии записан, время изменения `default.toml` обновилось, `config.toml` не изменился; нажатие Ctrl+Super+S, затем Ctrl+Super+W записывает workspace в конфиг, а `Super+Tab Super+S` больше не назначено ни на одно действие

#### Scenario: Отделение окна
- **WHEN** на столе 1 активен `work`, активно принятое в него окно Alacritty, и нажато Super+Backspace
- **THEN** окно закрывается и в составе `work` его больше нет, остальные окна `work` на местах; `hyprctl binds` содержит Super+Backspace

#### Scenario: Окно в половину рабочей области
- **WHEN** при активном плавающем окне нажато Alt+Super+Влево, зарезервированных зон нет, `gap = 5`
- **THEN** окно получает положение 10,10 и размер 1905×2140 на мониторе 3840×2160

#### Scenario: Окно в позицию рабочей области
- **WHEN** при активном плавающем окне нажато Ctrl+Alt+Super+V, затем Ctrl+Alt+Super+C, панель резервирует 330 px слева, `gap = 5`
- **THEN** окно получает положение 2090,1085 и размер 1740×1065, затем 1215,10 и 1740×2140

#### Scenario: Развёрнутое окно с отступами
- **WHEN** при активном плавающем окне нажато Alt+Super+PageUp, панель резервирует 330 px слева на мониторе 3840×2160, `gap = 5`
- **THEN** окно получает положение 340,10 и размер 3490×2140, а повторное нажатие Alt+Super+PageUp возвращает ему прежние положение и размер

#### Scenario: Приложение одним сочетанием
- **WHEN** нажато Super+C при поднятом workspace work
- **THEN** окно Chromium становится главным в центральной ячейке, а прежнее главное окно занимает его ячейку; Super+Delete закрывает активное окно

#### Scenario: Браузер в текущий workspace
- **WHEN** `surf` активен на столе 2, пользователь на столе 1 с активным `work` и нажимает Shift+Super+V
- **THEN** окно Chrome профиля AI.dev2026 появляется на столе 1 и входит в `work`, оставаясь в `surf`; нажатие Super+V после этого переводит на стол 2 к `surf`, и окно уходит туда вслед за пользователем

#### Scenario: Перенос окна на стол
- **WHEN** при активном окне нажато Super+Shift+3
- **THEN** окно оказывается на столе «3», стол «3» становится активным, окно остаётся в фокусе

#### Scenario: Перенос workspace на стол
- **WHEN** на столе 2 активен `surf` и нажато Ctrl+Super+3
- **THEN** активным становится стол 3, все окна `surf` оказываются на нём, а Ctrl+Super+2 возвращает их на стол 2

#### Scenario: Расстановка по конфигу
- **WHEN** окна стола передвинуты мышью и нажато Ctrl+Super+Пробел
- **THEN** окна приложений возвращаются на свои места по описанию активного workspace, раскладка клавиатуры не меняется

#### Scenario: Блокировка
- **WHEN** нажато Super+L
- **THEN** экран закрывает hyprlock, после ввода пароля сессия продолжается со всеми окнами

#### Scenario: Подсказка клавиш
- **WHEN** при русской раскладке нажато Shift+Super+/, затем Shift+Super+/ ещё раз
- **THEN** первое нажатие показывает окно подсказки клавиш, второе скрывает его; `hyprctl binds` содержит привязку с клавишей `slash` и модификаторами Super и Shift

#### Scenario: Привязок в конфиге Hyprland нет
- **WHEN** выполнен поиск `hl.bind` в `~/.config/hypr/hyprland.lua`
- **THEN** совпадений нет, а `hyprctl binds` содержит все сочетания из таблицы

#### Scenario: Окно 1920×1080 по центру рабочей области
- **WHEN** при активном окне, сдвинутом в 400,300, нажато Alt+Super+Enter, панель резервирует 330 px слева на мониторе 3840×2160
- **THEN** окно плавающее, его положение 1125,540 и размер 1920×1080 — центр области справа от панели, а не монитора
