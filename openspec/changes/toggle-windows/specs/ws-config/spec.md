## ADDED Requirements

### Requirement: Окно-переключатель в конфиге
Приложение с полем `toggle = true` в разделе `[apps.<имя>]` MUST считаться окном-переключателем (спецификация ws-daemon, «Окно-переключатель»). У переключателя действуют обычные поля приложения (`cmd`, `args`, `cwd`, `env`, `class`, `title`, `chain`, `dialog_title`); поле `class` и место `rect` MUST быть заданы. Клавиша переключателя — его собственный `chain`.

Место `rect` приложения MUST задаваться либо обеими координатами `x` и `y` вместе с `w` и `h`, либо только размером `w` и `h`: без координат окно MUST стоять по центру рабочей области (монитор без зон, зарезервированных слоями) с этим размером. Место без координат MUST допускаться только у окна-переключателя; ячейки шаблонов и `rect` записей workspace по-прежнему MUST задавать все четыре числа.

Проверка конфига (`workspaced check` и чтение конфига демоном) MUST отклонять с понятной ошибкой, называющей приложение:

- переключатель в таблице `apps` любого workspace;
- переключатель с полем `family` и приложение, чьё `family` называет переключатель;
- переключатель без `class` или без `rect`;
- `rect` с одной координатой из двух и `rect` без координат у приложения без `toggle = true`;
- клавишу переключателя, совпадающую с собственной клавишей другого приложения или с ключом `chain` записи любого workspace;
- действие `[[binds]]` `{ app = "<переключатель>", … }` с ключом `workspace` или `pull`; ключ `new` и стол `desktop` с переключателем допустимы.

Сводка `workspaced check` MUST помечать переключатель словами «окно-переключатель».

#### Scenario: Telegram — переключатель по центру
- **WHEN** в конфиге `[apps.telegram]` с `toggle = true`, `chain = "SUPER+T"`, `cmd = "Telegram"`, `class = '^org\.telegram\.desktop$'` и `rect = { w = 1000, h = 1000 }`, панель резервирует 330 px слева на мониторе 3840×2160
- **THEN** `workspaced check` сообщает, что конфиг корректен, и печатает «приложение telegram (окно-переключатель)»; место окна — 1585,580 1000×1000

#### Scenario: Переключатель в разделе workspace
- **WHEN** в таблицу `[workspaces.work.apps]` добавлена запись `telegram = "left"`
- **THEN** `workspaced check` отклоняет конфиг с ошибкой «workspace work: приложение telegram — окно-переключатель (toggle = true), оно не входит ни в один workspace», а работающий демон продолжает с прежним конфигом

#### Scenario: Место без координат у обычного приложения
- **WHEN** у `[apps.calc]` без `toggle` задано `rect = { w = 600, h = 400 }`
- **THEN** проверка отклоняет конфиг и называет приложение `calc` и поле `toggle`

#### Scenario: Клавиша переключателя занята
- **WHEN** у herdr `chain = "SUPER+T"`, и у переключателя telegram тоже `chain = "SUPER+T"`
- **THEN** проверка отклоняет конфиг: клавиша окна-переключателя должна быть своей

#### Scenario: Переключатель без вариантов
- **WHEN** у приложения `tg-media` задано `family = "telegram"`, а telegram — переключатель
- **THEN** проверка отклоняет конфиг и называет `tg-media`
