## MODIFIED Requirements

### Requirement: Фокус кликом и рамка активного окна
Фокус окна MUST переходить только по клику в области окна: наведение курсора фокус не переводит, в том числе при переходе между плавающими окнами. Курсор MUST NOT переноситься к окну при смене фокуса диспетчером (активация из плитки стола, Alt+Tab). Рамка окна MUST быть шириной 1 px, как рамка плиток панели; рамка активного окна MUST быть цвета рамки плиток панели (yellow Tokyo Night `#E0AF68`), рамка неактивного окна — тёмно-зелёной `#2D6A4F`. Слои с клавиатурой по требованию (поле фильтра панели) MUST NOT удерживать клавиатуру при клике по окну (`misc.layers_hog_keyboard_focus` выключен). Запрос активации от приложения (xdg-activation: клик по уведомлению Telegram в панели Quickshell, открытие ссылки из другой программы) MUST переводить фокус на окно приложения и переходить на его стол (`misc.focus_on_activate` включён); окно-переключатель, спрятанное демоном на `special:pool`, при активации MUST показываться на текущем столе, а открытый композитором `special:pool` MUST закрываться (спецификация ws-daemon, «Окно-переключатель»); левый клик по уведомлению панели MUST выполнять действие уведомления по умолчанию и закрывать его.

#### Scenario: Наведение не меняет фокус
- **WHEN** в фокусе терминал, а курсор проходит над окном браузера без клика
- **THEN** фокус клавиатуры остаётся у терминала, браузер не поднимается над ним

#### Scenario: Активация из панели без переноса курсора
- **WHEN** пользователь кликает по иконке окна в плитке стола
- **THEN** окно получает фокус и поднимается наверх, а курсор остаётся на панели

#### Scenario: Клик по уведомлению
- **WHEN** окно Telegram на столе 3, пользователь на столе 1 кликает левой кнопкой по уведомлению Telegram
- **THEN** уведомление закрывается, композитор переходит на стол 3, окно Telegram получает фокус и поднимается наверх

#### Scenario: Клик по уведомлению при спрятанном окне Telegram
- **WHEN** окно Telegram спрятано клавишей Super+T, пользователь на столе 1 кликает левой кнопкой по уведомлению Telegram
- **THEN** уведомление закрывается, композитор остаётся на столе 1, окно Telegram появляется на нём в месте переключателя с фокусом, `hyprctl monitors -j` показывает пустой `specialWorkspace`

#### Scenario: Цвет рамки
- **WHEN** окно в фокусе
- **THEN** его рамка жёлтая `#E0AF68` шириной 1 px, как рамки плиток панели; `hyprctl getoption general:border_size` показывает 1, а рамки окон без фокуса тёмно-зелёные `#2D6A4F`
