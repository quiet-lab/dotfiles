# Design: Токен панели ввода

## Решение

Контракт панели ввода с форком herdr — токен `input_for` источника
`claude-input` на панели Neovim, значение — `pane_id` панели Claude Code
той же вкладки. По нему форк находит панель ввода, чтобы передать ей фокус
при выборе workspace в Spaces и агента в Agents, а также следить
за состоянием blocked.

## Почему токен, а не переменная среды

`CLAUDE_INPUT_PANE` видна только процессу внутри панели; сервер herdr
переменных среды панелей не читает. Токен панели — состояние сервера,
доступное форку напрямую и видимое в `herdr pane get` (`tokens`).

## Границы

- Токен ставится один раз, после `pane split`; при пересоздании панели буфера
  `open` ставит его заново, на живую панель повторно не ставится.
- `close` токен не снимает: панель закрывается целиком.
- Ошибка `report-metadata` (herdr без `--token`, код 2) не прерывает хук.
