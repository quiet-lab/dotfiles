## Why

Пользователь 6 ноября 2026 поставил требования к Neovim при системной
русской раскладке: встроенные команды и горячие клавиши работают без
переключения раскладки в нормальном и других режимах, включая назначенные
вручную в режиме вставки, в командной строке и поиске; flash.nvim принимает
русский поиск, а метки выбираются по-русски; решение охватывает все
установленные плагины, читающие клавиши; поведение разобрано по режимам;
ручных переключений раскладки как можно меньше; модуль `claude-input`
не ломается. Критерий выбора — наибольшее покрытие случаев при наименьшем
числе переключений, объём кода значения не имеет. Разбор вариантов — проект
«Neovim в русской раскладке» задачи nvim-layout в каталоге результатов.

## What Changes

- Локальный модуль Neovim `ru-layout` (`dot_config/nvim/local/ru-layout`):
  таблица ЙЦУКЕН ↔ QWERTY из карты XKB пользователя и `langmap` из неё;
  раскладка из Hyprland по событиям сокета; подмена API привязок с
  кириллическим дублем каждой латинской привязки; знаки по раскладке;
  обёртки `r` и `@`; перевод строки `:` по `<CR>` и `<Tab>` и переключатель
  `<M-l>` в `/`; ответы `confirm()` и `:s///c`; кириллические метки и поиск
  по обеим раскладкам во flash; обёртки плагинов, читающих клавиши;
  привязки режима `t` для программ из списка в терминале.
- Системная раскладка не переключается ни в `:`, ни в терминале.
- Подключение: `lua/config/lazy.lua` (подмена API до `lazy.setup`),
  `lua/plugins/ru-layout.lua`.
- Тесты модуля на оснастке с двойником Hyprland, сторожевой тест на новых
  потребителей `getchar`; запуск после каждого `:Lazy update`.
- Документ `docs/ru-layout.md`, строка в `docs/README.md`, абзац в
  `AGENTS.md`.

## Capabilities

### New Capabilities
- `ru-layout`: работа Neovim в русской раскладке без переключения системной
  раскладки.

### Modified Capabilities

Нет: спецификация `claude-input` не меняется.

## Impact

- `dot_config/nvim/local/ru-layout/**` (новый), `dot_config/nvim/lua/plugins/ru-layout.lua`
  (новый), `dot_config/nvim/lua/config/lazy.lua`.
- `docs/ru-layout.md` (новый), `docs/README.md`, `AGENTS.md`.
- Стоимость запуска Neovim растёт на установку привязок и проход по ним;
  замер — в отчёте задачи.
