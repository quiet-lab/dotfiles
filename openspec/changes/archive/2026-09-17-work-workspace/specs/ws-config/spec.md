## MODIFIED Requirements

### Requirement: Файл конфига и его разделы
Демон MUST читать конфиг из `~/.config/workspaced/config.toml` (файл под chezmoi). Файл MUST состоять из разделов: `[env]` — общие переменные окружения; `[keys]` — цепочки служебных действий `save_workspace`, `sessions`, `next_workspace` и список `reserved` зарезервированных сочетаний; `[templates.<имя>]` — шаблон геометрии с полем `main` (имя главной ячейки) и таблицей `cells`, где каждая ячейка — прямоугольник `{ x, y, w, h }`; `[apps.<имя>]` — приложение с полями `cmd` (обязательно), `args` (массив), `cwd`, `env` (таблица), `chain`, `class` и `title` (регулярные выражения для захвата открытого окна по классу и заголовку; `title` без `class` не допускается); `[startup]` — `workspace` (имя существующего workspace, который поднимается при старте демона) и `desktop` (стол 1…8, по умолчанию 1); `[workspaces.<имя>]` — workspace с полями `template` (обязательно), `main` (имя приложения в главной ячейке по умолчанию), `icon`, `chain`, `env` и таблицей `apps`, где значение — имя ячейки шаблона либо таблица `{ rect = { x, y, w, h } }` для окна вне ячеек; `[[binds]]` — записи с полем `chain`, ровно одним из полей действия `action`, `exec`, `dispatch`, `lua` и необязательными `range`, `locked`, `repeating`, `mouse`, `release`. Координаты прямоугольников MUST отсчитываться от левого верхнего угла экрана: целое число — пиксели, строка с процентом — доля ширины или высоты монитора; смешивать формы в одном прямоугольнике MUST быть можно. Координаты MUST допускать отрицательные значения, а размеры — значения больше экрана: окно может выходить за его края частично с любой стороны, демон MUST передавать такие значения композитору без обрезания и без сдвига внутрь экрана. Необязательный ключ `gap` в корне файла задаёт зазор в пикселях, на который каждое окно отступает внутрь своей ячейки; по умолчанию 0. Неизвестные ключи MUST приводить к предупреждению в журнале, но не к отказу.

#### Scenario: Минимальный конфиг
- **WHEN** файл содержит один шаблон `halves` с ячейками `left` и `right`, одно приложение `terminal` с `cmd = "wezterm-gui"` и один workspace `work` с `template = "halves"`, `main = "terminal"` и `apps = { terminal = "right" }`
- **THEN** `workspaced check` завершается успешно и выводит один workspace, одно приложение и один шаблон

#### Scenario: Класс, заголовок и стартовый workspace
- **WHEN** у приложения `herdr` заданы `class = "^org\\.wezfurlong\\.wezterm$"` и `title = "^herdr · "`, а в `[startup]` — `workspace = "work"`
- **THEN** `workspaced check` завершается успешно; конфиг с `title` без `class`, с некорректным регулярным выражением или с `startup.workspace`, которого нет среди workspace, отклоняется с указанием поля

#### Scenario: Проценты и пиксели в одной ячейке
- **WHEN** ячейка задана как `{ x = 330, y = 0, w = "50%", h = "100%" }` на мониторе 3840×2160
- **THEN** демон считает прямоугольник 330,0 размером 1920×2160

#### Scenario: Окно шире экрана со сдвигом за левый край
- **WHEN** ячейка задана как `{ x = -400, y = -150, w = 5000, h = 2600 }` и в неё поставлено окно при `gap = 0`
- **THEN** `hyprctl clients -j` показывает у окна положение −400,−150 и размер 5000×2600

#### Scenario: Ссылка на несуществующую ячейку
- **WHEN** workspace ссылается на ячейку `top`, которой нет в его шаблоне
- **THEN** `workspaced check` завершается с ошибкой, называющей workspace, приложение и ячейку; демон продолжает работать с прежним конфигом

#### Scenario: Запись привязки с двумя действиями
- **WHEN** запись `[[binds]]` содержит и `exec`, и `dispatch`
- **THEN** `workspaced check` завершается с ошибкой, называющей цепочку записи и оба поля
