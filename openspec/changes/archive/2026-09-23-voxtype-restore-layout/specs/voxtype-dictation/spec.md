## ADDED Requirements

### Requirement: Раскладка окна после диктовки

После окончания вывода текста VoxType MUST вызывать
`~/.local/bin/handmade-scripts/voxtype-restore-layout` (источник chezmoi
`dot_local/bin/handmade-scripts/executable_voxtype-restore-layout`) через
ключ `post_output_command` раздела `[output]` конфига
`~/.config/voxtype/config.toml` (источник chezmoi
`dot_config/voxtype/config.toml`). Скрипт MUST для каждой физической
клавиатуры с ненулевой группой раскладки переключить группу на 0 и сразу
обратно одним пакетным вызовом `hyprctl --batch`; клавиатуры с группой 0
MUST NOT трогать. Перехват MUST срабатывать по событию «вывод текста
закончен»; таймеров и опроса состояния клавиатуры или раскладки MUST NOT
быть.

#### Scenario: Диктовка при русской раскладке

- **WHEN** главная клавиатура находится на раскладке RU и диктовка
  окончена
- **THEN** окно в фокусе получает событие `modifiers` с группой 1 и печатает
  кириллицу, а плитка раскладки панели по-прежнему показывает RU

#### Scenario: Диктовка при английской раскладке

- **WHEN** главная клавиатура находится на раскладке EN (группа 0)
  и диктовка окончена
- **THEN** скрипт не переключает ни одной клавиатуры, окно продолжает
  печатать латиницу без лишних событий `modifiers`

#### Scenario: Проверка без нажатий через wev

- **WHEN** окно `wev -f wl_keyboard` переведено в фокус, выполнено
  `wtype x`, а затем скрипт `voxtype-restore-layout`
- **THEN** после строки `keymap … size: 41878` в выводе `wev` приходит
  событие `modifiers` с номером группы главной клавиатуры (проверка
  подробно описана в `docs/media-and-portals.md`)
