## Context

См. proposal.md (Why). Техническая ситуация: легаси-блоки физически перемешаны с кодом дашборда в одном `eww.yuck` — виджет `workspaces` и окно `netmenu`, нужные дашборду, определены ниже секции «ЛЕГАСИ»; глобальные CSS-правила обслуживают и легаси, и дашборд. Автотестов нет; верификация только визуальная (`eww reload` + осмотр). Текущее состояние закоммичено, откат возможен одним `git revert`.

## Goals / Non-Goals

**Goals:**

- Удалить весь мёртвый легаси-код из `eww.yuck`, `eww.scss`, `scripts/popup` по точной границе «легаси vs дашборд».
- Сохранить работоспособность всех плиток дашборда без изменений поведения.
- Почистить шапку `eww.yuck` от ссылки на несуществующую спеку.

**Non-Goals:**

- Автозапуск eww при логине — будет требованием будущей спеки `eww-shell`.
- Чистка прочих сирот: ветка `net-editor` в popup уже сейчас никем не вызывается (tile зовёт `nm-connection-editor` напрямую) — отдельная уборка.
- Реорганизация/перемещение уцелевших определений (`workspaces`, `netmenu`) внутри файлов.
- Создание спецификаций — следующий change.

## Decisions

1. **Граница легаси зафиксирована списком.** Удаляются: окна `bar` и `calendar`; виджеты `launcher`, `wifi`, `volum`, `control`, `time`, `cal`, `power`, `left`, `right`, `bar`, `stub`; poll'ы `wifi-icon`, `wifi-name`, `calendar_day`, `calendar_month`, `calendar_year`; переменные `volum`, `power`. Остаются: `workspaces` + deflisten `workspace`, окно `netmenu` + poll `netmenu-content`. Альтернатива — удалять «по использованию» лениво: отвергнуто, потому что половина легаси уже неиспользуема, и границу всё равно придётся фиксировать явно.

2. **Глобальные CSS-селекторы заменяются tile-версиями.** Блоки `scale { min-width: 90px }`, `scale trough { ... }`, `.volbar trough highlight { ... }` на уровне файла дублируют правила внутри `.volume-tile` (`scale trough` и `.volbar trough highlight`). Глобальные удаляются вместе с легаси; поведение volume-tile сохраняют его собственные селекторы. Альтернатива — оставить глобальные как «общие»: отвергнуто, это источник скрытых связей, из-за которых чистка опасна.

3. **Popup-сироты удаляются сразу.** Ветки `launcher` (rofi), `wifi` (nmtui), `calendar` вызывались только из легаси-виджетов. Оставлять недостижимые ветки — тот же мёртвый код, что и виджеты. `audio` и `netmenu*` остаются (используются volume-tile и network-tile).

4. **Порядок: yuck → SCSS → popup, проверка после каждого файла.** `eww reload` после удаления из yuck ловит битые ссылки на переменные/виджеты немедленно; SCSS и скрипт не влияют на парсер yuck. Альтернатива — один большой коммит правок без промежуточных проверок: отвергнута, отладка вслепую дороже.

5. **Один коммит на весь change.** Откат одним `git revert`; промежуточная верификация выполняется в рабочем дереве до коммита.

## Risks / Trade-offs

- [Глобальный `scale { min-width: 90px }` мог влиять на disk-bar] → после удаления сравнить ширину полос дисков и громкости визуально; при деградации вернуть правило точечно в `.disks-tile .disk-bar` / `.volume-tile`.
- [Легко зацепить живое: `workspaces` стоит внутри легаси-секции] → удалять по именам из списка решения 1, а не «диапазонами строк»; после reload проверить плитку столов и netmenu.
- [`popup calendar` исчезает — отдельный календарь больше не открыть] → осознанно: календарь встроен в clock-tile (см. proposal).
- [Нет автотестов] → чеклист ручной верификации в tasks.md обязателен к прохождению.

## Migration Plan

1. Правки `eww.yuck` → `eww reload` → осмотр колонки целиком.
2. Правки `eww.scss` → `eww reload` → осмотр цветов/полос.
3. Правки `scripts/popup` → проверка кнопок громкости (pavucontrol) и netmenu.
4. Коммит; откат при проблемах — `git revert`.
