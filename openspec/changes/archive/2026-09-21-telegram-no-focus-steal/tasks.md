## 1. Настройка Telegram (пользователь)

- [x] 1.1 В Telegram Desktop открыть «Настройки» → «Уведомления и звуки»
      и выключить переключатель «Подсветка окна» (в английском
      интерфейсе «Draw attention to the window»; в поиске настроек он
      находится по словам flash, bounce, taskbar). Остальные переключатели
      уведомлений не трогать: уведомления dunst должны приходить как раньше

## 3. Проверка вживую (пользователь)

- [x] 3.1 После выключения настройки уйти на стол 1 и дождаться сообщения
      в активном групповом чате: уведомление dunst появляется, активный стол
      остаётся 1, фокус остаётся у окна на столе 1, окно Telegram не поднимается
      и не получает жёлтую рамку активного окна. Если нужна запись событий
      композитора, до сообщения запустить в терминале

      ```bash
      python3 -c 'import os, socket
      rt = os.environ["XDG_RUNTIME_DIR"]
      sig = os.environ["HYPRLAND_INSTANCE_SIGNATURE"]
      s = socket.socket(socket.AF_UNIX)
      s.connect(rt + "/hypr/" + sig + "/.socket2.sock")
      for line in s.makefile("r", errors="replace"):
          print(line, end="", flush=True)'
      ```

      — при сообщении в выводе не должно быть строк `urgent>>`,
      `activewindow>>org.telegram.desktop` и `workspace>>2`, а строка
      `openlayer>>notifications` (показ уведомления dunst) остаётся
- [x] 3.2 Кликнуть левой кнопкой по уведомлению Telegram: композитор
      переходит на стол окна Telegram, окно получает фокус, в нём открыт
      топик того сообщения, о котором было уведомление
- [x] 3.3 Открыть ссылку из другой программы (например, из herdr
      в терминале): окно браузера получает фокус, композитор переходит
      на его стол
- [x] 3.4 Если на шаге 3.1 окно всё же поднимается само — вернуться к разделу
      «Risks / Trade-offs» в `design.md`: настройка не была причиной,
      нужен следующий разбор, а не правило окна
