# Design: Переоткрытие панели ввода

## Решение

Режим `reopen` хука не копирует код открытия: он закрывает старую панель,
удаляет файл соответствия и продолжает выполнение тем же скриптом, поэтому
ранний выход `open` «панель уже есть и жива» не срабатывает, а деление панели,
запуск `nvim +ClaudeInput`, токен и `herdr pane activate` общие с `open`.

## Откуда берётся старая панель

Сначала файл соответствия, затем токен `input_pane` панели Claude Code
(`herdr pane get`, поле `tokens`): файл мог быть утерян, токен ставит `open`.
Нет ни того ни другого — закрывать нечего, панель просто открывается.
Зависший nvim завершает закрытие панели herdr; процессы по образцу не трогаются.

## Область действия

Проверка предка `claude` с терминалом на стандартном вводе проходит и из
инструмента Bash: его родитель — процесс Claude Code, а не промежуточная
оболочка, поэтому отдельной проверки по окружению herdr не нужно.

## Сообщения

Режим вызывается пользователем, поэтому невозможность открыть панель (высота
панели Claude ниже 20 строк, herdr не создал панель, нет `pane activate`)
выводится в stderr с кодом 1, а успех — строкой с идентификатором новой
панели в stdout.
