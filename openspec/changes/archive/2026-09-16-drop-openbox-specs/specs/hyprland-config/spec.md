## ADDED Requirements

### Requirement: Эффекты окон, слоёв и курсор
Конфиг MUST включать размытие, скругление углов, тени и анимации окон и слоёв. Прозрачность и размытие: окно в фокусе с непрозрачностью 0.9, без фокуса 0.7, полноэкранное и модальные диалоги непрозрачные; браузеры и видеопроигрыватели непрозрачные и без размытия независимо от фокуса, игры в фокусе непрозрачные; размытие фона только у терминалов и neovide в фокусе; скругление 8 px, мягкая тень. Для слоя панели Quickshell (пространство имён `panel`) конфиг MUST задавать правило слоя с размытием и порогом прозрачности, при котором полностью прозрачные промежутки между плитками не размываются и не затемняются, а плитки получают размытый фон. Курсор MUST быть аппаратным (`cursor:no_hardware_cursors = false`); конфиг MUST сохранять возможность переключить курсор на программный одной настройкой.

#### Scenario: Прозрачность окон
- **WHEN** в фокусе терминал, а рядом окно браузера без фокуса
- **THEN** терминал полупрозрачный с размытым фоном, браузер непрозрачный и без размытия; при переводе фокуса на браузер его вид не меняется, а терминал становится прозрачнее

#### Scenario: Размытие панели
- **WHEN** панель Quickshell открыта поверх обоев и окон
- **THEN** плитки панели полупрозрачные с размытым фоном, а промежутки между ними показывают обои и окна без размытия и затемнения

#### Scenario: Эффекты не дают рывков
- **WHEN** в сессии открыты четыре окна и панель Quickshell, а пользователь перемещает плавающее окно и переключает рабочие столы
- **THEN** анимации идут без заметных рывков, загрузка GPU по `nvidia-smi` не достигает насыщения

### Requirement: Поведение окон
Новые окна MUST открываться плавающими с сохранением возможности перевести окно в мозаичный режим привязкой; расположение окон workspace по ячейкам задаёт демон workspaced (спецификация ws-daemon), собственная раскладка зон в конфиге Hyprland MUST NOT создаваться. Помимо `special:hidden` для окон, скрытых пользователем, сессия MUST допускать специальный стол `special:pool` для окон, припаркованных демоном; переключение на него привязкой MUST NOT предусматриваться. Приложения Xwayland MUST поддерживаться: Xwayland включён, окна GTK-программ, запущенных с `GDK_BACKEND=x11`, и приложений AppImage отображаются без чёрных областей.

#### Scenario: Новое окно плавающее
- **WHEN** из сессии запущен терминал
- **THEN** `hyprctl activewindow` показывает `floating: 1`

#### Scenario: Окно Xwayland
- **WHEN** из сессии запущена GTK-программа с `GDK_BACKEND=x11`
- **THEN** `hyprctl clients` показывает для неё `xwayland: 1`, окно отрисовано полностью

#### Scenario: Припаркованное окно
- **WHEN** демон перенёс окно на `special:pool`
- **THEN** `hyprctl clients -j` показывает у окна стол `special:pool`, окно не видно ни на одном столе, `hyprctl binds` не содержит привязки для показа `special:pool`

## MODIFIED Requirements

### Requirement: Рабочие столы
Сессия MUST предоставлять восемь рабочих столов с именами «1»…«8», все на мониторе DP-2. Стол с номером N MUST существовать до первого перехода на него, чтобы переключение и перенос окон работали с любого стола.

#### Scenario: Переход на пустой стол
- **WHEN** пользователь переходит на стол 7, на котором нет окон
- **THEN** `hyprctl activeworkspace` показывает стол с именем «7» на DP-2

## REMOVED Requirements

### Requirement: Эффекты и курсор
**Reason**: Требование ссылалось на правила picom из удалённой X11-сессии.
**Migration**: Те же значения заданы требованием «Эффекты окон, слоёв и курсор».

### Requirement: Поведение окон в переходный период
**Reason**: Переходный период с Openbox закончен, Openbox удалён.
**Migration**: Требование «Поведение окон» с тем же содержанием без ссылки на Openbox.
