## MODIFIED Requirements

### Requirement: Скрипты метрик панели
Метрики шкал и дисков MUST вычисляться скриптами из каталога `dot_config/quickshell/panel/scripts/` (в `$HOME` — `~/.config/quickshell/panel/scripts/`, пути без префикса `executable_`). Скрипт каждой метрики MUST за один вызов выводить ровно одну строку JSON с числовым значением и температурным классом (`{"value":<число>,"class":"<класс>"}`); панель MUST NOT вызывать для одной метрики отдельные скрипты за значением и за классом. Скрипты MUST быть переносимыми оболочечными сценариями (`sh -n` без ошибок).

#### Scenario: Вызов скрипта метрики
- **WHEN** скрипт загрузки CPU запущен из терминала
- **THEN** в выводе одна строка JSON с полями `value` (целое число 0–100) и `class` (одно из `t-low`, `t-mid`, `t-high`, `t-crit`), которая разбирается без ошибок

#### Scenario: Ошибка в выводе скрипта
- **WHEN** скрипт завершился с ошибкой или вывел строку, не являющуюся JSON
- **THEN** панель сохраняет предыдущее значение шкалы, не завершается и не выводит окно с ошибкой; следующий опрос выполняется по расписанию

### Requirement: Круговые шкалы
Панель MUST показывать три плитки шкал (CPU, RAM, GPU) размером 100×100 px в порядке CPU, RAM, GPU на месте, заданном спецификацией qs-shell. Каждая плитка MUST содержать заголовок с именем шкалы и температурой (для RAM — общим объёмом) и круговую шкалу размером 70×70 px с толщиной дуги 10 px по центру плитки. В центре круга MUST быть подпись `<значение>%` полужирным шрифтом 16 px цветом основного текста; заголовок — полужирным 15 px. Дуга MUST заполняться пропорционально значению 0–100 по часовой стрелке, фон дуги — rgba(169,177,214,0.15); цвет заполненной части дуги задаётся температурным классом значения.

#### Scenario: Центральная подпись
- **WHEN** загрузка CPU равна 42
- **THEN** в центре круга виден текст «42%», дуга заполнена на 42 % и окрашена в #39FF14

#### Scenario: Плитки в колонке
- **WHEN** панель открыта
- **THEN** под плиткой погоды видны три плитки шкал CPU, RAM, GPU с заголовками «CPU 61°», «RAM 65G», «GPU 45°»
