## ADDED Requirements

### Requirement: Клавиши рабочих столов
Клавиши столов MUST идти по столам сессии 1…N, где N — число столов из ключа `desktops` конфига демона (спецификация ws-config, «Число столов»); в конфиге сессии N = 4. Super+1…N MUST переводить на стол с этим номером, Shift+Super+1…N — переносить активное окно на этот стол и переходить вслед за ним, Ctrl+Super+1…N — переносить активный workspace текущего стола на этот стол и переходить вслед за ним командой демона `move-desktop`, окна всех его приложений едут вместе с ним (спецификация ws-daemon, «Перенос workspace на стол»). Сочетания Super+цифра, Shift+Super+цифра и Ctrl+Super+цифра для цифр больше N сессия MUST NOT занимать.

#### Scenario: Четыре стола
- **WHEN** в конфиге демона `desktops = 4`
- **THEN** `workspaced keys --list` содержит SUPER+1…SUPER+4, SUPER+SHIFT+1…4 и SUPER+CTRL+1…4 и ни одного из этих сочетаний с цифрами 5…8; Super+3 переводит на стол «3», Ctrl+Super+2 переносит активный workspace на стол 2

#### Scenario: Цифра за числом столов
- **WHEN** пользователь нажимает Super+6
- **THEN** привязки у сочетания нет, стол не меняется
