## MODIFIED Requirements

### Requirement: Переключатель раскладки
Плитка раскладки MUST показывать код активной раскладки заглавными буквами (US, RU), определённый по имени раскладки из событий Hyprland `activelayout` от любой физической клавиатуры (у каждой клавиатуры в Hyprland своя раскладка, признак `main` переходит между ними, поэтому события MUST NOT фильтроваться по имени клавиатуры, запомненному при старте); события виртуальных клавиатур `hl-virtual-keyboard-*` (wtype) MUST игнорироваться. При старте панели код MUST браться из текущего состояния главной клавиатуры в устройствах Hyprland. Обновление MUST происходить по событиям, без опроса по таймеру. Клик по плитке MUST переключать раскладку на следующую по кругу средствами Hyprland (`hyprctl switchxkblayout … next`); карта XKB (`~/.config/X11/xkb_custom`) при этом не меняется, сочетания Win+Alt+E, Win+Alt+R и Win+Пробел продолжают переключать раскладку сами. Подсказка при наведении MUST содержать текст «Переключить раскладку».

#### Scenario: Смена раскладки сочетанием клавиш
- **WHEN** пользователь переключает раскладку сочетанием Win+Alt+R, затем Win+Alt+E
- **THEN** подпись плитки меняется на «RU», затем на «US», без клика по плитке и без заметной задержки

#### Scenario: Смена раскладки кликом
- **WHEN** пользователь кликает по плитке раскладки при активной раскладке US
- **THEN** активной становится раскладка RU у клавиатуры, от которой пришло последнее событие `activelayout` (при старте — у главной), `hyprctl devices` показывает её у этой клавиатуры, подпись плитки обновляется

#### Scenario: Переключение на не главной клавиатуре
- **WHEN** подключено несколько клавиатур, признак `main` у Hyprland стоит не на той, на которой пользователь переключил раскладку сочетанием клавиш
- **THEN** подпись плитки всё равно меняется по событию `activelayout` этой клавиатуры

#### Scenario: Состояние при старте панели
- **WHEN** панель запущена при активной раскладке RU
- **THEN** плитка сразу показывает «RU», не дожидаясь первого переключения
