## MODIFIED Requirements

### Requirement: Карта XKB и зарезервированные сочетания
Конфиг MUST загружать карту клавиатуры файлом `~/.config/X11/xkb_custom` через `input.kb_file`. Карта MUST переключать раскладку сама: Win+Пробел по кругу, Win+Alt+E на US, Win+Alt+R на RU. Эти три сочетания MUST оставаться за картой XKB: ни одна привязка конфигурации MUST NOT занимать их, иначе композитор перехватит их раньше XKB. Одиночное Alt+буква MUST доставаться приложению: клавиши фиксации раскладки MUST давать третий уровень только при Alt вместе с Super, а Alt и Super, когда третьего уровня они не дают, MUST передаваться приложению вместе с буквой.

#### Scenario: Раскладки переключаются картой
- **WHEN** в терминале сессии нажаты Win+Alt+R, затем Win+Alt+E, затем Win+Пробел
- **THEN** ввод переключается на русскую раскладку, затем на английскую, затем по кругу, а `hyprctl devices` показывает активную раскладку

#### Scenario: Alt+буква достаётся приложению
- **WHEN** в окне браузера на Chromium нажато Alt+E
- **THEN** открывается меню браузера, раскладка не меняется, а `hyprctl devices` показывает прежнюю активную раскладку
