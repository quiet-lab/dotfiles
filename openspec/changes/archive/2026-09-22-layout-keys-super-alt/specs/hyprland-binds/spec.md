## MODIFIED Requirements

### Requirement: Зарезервированные сочетания
Список `reserved` раздела `[keys]` конфига демона MUST содержать сочетания, которые ни одна привязка занимать не может, с комментарием о причине: сочетания карты XKB Super+Пробел, Super+Alt+E и Super+Alt+R, которые композитор перехватил бы раньше XKB, и намеренно свободное Alt+Super+Пробел. Проверка конфига MUST отклонять привязку на любое из этих сочетаний, а конфиг MUST NOT назначать их действиям без отдельного решения.

#### Scenario: Сочетание без действия
- **WHEN** нажато Alt+Super+Пробел
- **THEN** ничего не происходит, `hyprctl binds` не содержит этого сочетания

#### Scenario: Попытка занять зарезервированное сочетание
- **WHEN** в `[[binds]]` добавлена запись с `chain = "SUPER+D"` и выполнена `workspaced check`
- **THEN** команда завершается с ошибкой, называющей `SUPER+D` как зарезервированное, демон продолжает работать с прежним конфигом
