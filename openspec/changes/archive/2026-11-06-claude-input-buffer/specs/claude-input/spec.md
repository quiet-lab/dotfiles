## ADDED Requirements

### Requirement: Панель буфера ввода открывается вместе с сессией Claude Code
Хук Claude Code `SessionStart` с событиями `startup` и `resume` MUST вызывать сценарий `~/.claude/hooks/herdr-claude-input.sh open`. Внутри herdr сценарий MUST делить панель Claude Code вниз без передачи фокуса так, чтобы область вывода новой панели была ровно 13 строк (`viewport_rows` в ответе `herdr pane get`), и запускать в ней процессом панели neovim с командой `ClaudeInput`. События `compact` и `clear` панель MUST NOT открывать.

#### Scenario: Запуск Claude Code в herdr
- **WHEN** в панели herdr запускается `claude`
- **THEN** под панелью Claude Code появляется панель с neovim, у неё `viewport_rows` равно 13, фокус остаётся у Claude Code, а neovim открыт в буфере `claude://input` в режиме вставки

### Requirement: Одна панель буфера на панель Claude Code
Идентификатор панели Claude Code панель буфера MUST получать переменной окружения `CLAUDE_INPUT_PANE`. Соответствие «панель Claude Code → панель буфера» MUST храниться файлом в `${XDG_STATE_HOME:-~/.local/state}/claude-input/`. Если файл указывает на живую панель, `open` MUST NOT создавать новую.

#### Scenario: Повторный старт для той же панели
- **WHEN** панель буфера для панели Claude Code уже открыта и сессия возобновляется (`SessionStart` с событием `resume`)
- **THEN** вторая панель не создаётся

### Requirement: Сценарий хука не действует вне своей области
Сценарий MUST ничего не делать и завершаться с кодом 0 вне herdr (`HERDR_ENV` не равна 1 или не задана `HERDR_PANE_ID`), у субагентов (поле `agent_id` во входе хука), у исполнителей duty (задана `DUTY_TASK`), при высоте панели Claude Code меньше 20 строк и при любой ошибке.

#### Scenario: Исполнитель duty
- **WHEN** Claude Code запущен с заданной переменной `DUTY_TASK`
- **THEN** сценарий не делит панель и завершается с кодом 0

#### Scenario: Вне herdr
- **WHEN** Claude Code запущен в терминале без herdr
- **THEN** сценарий ничего не выводит и завершается с кодом 0

### Requirement: Панель буфера закрывается с завершением сессии
Хук `SessionEnd` MUST вызывать `herdr-claude-input.sh close`, который закрывает панель буфера, записанную для панели Claude Code, и удаляет файл соответствия. Выход из neovim (`:q`) MUST закрывать панель буфера.

#### Scenario: Выход из Claude Code
- **WHEN** пользователь выходит из Claude Code, под которым открыта панель буфера
- **THEN** панель буфера закрывается, файла соответствия для панели Claude Code не остаётся

### Requirement: Буфер ввода повторяется в строке ввода Claude Code
Команда neovim `ClaudeInput` MUST открывать единственный буфер `claude://input` (`buftype=acwrite`, без файла подкачки, `filetype=markdown`) и переводить neovim в режим вставки. Каждое изменение буфера (`TextChanged`, `TextChangedI`, `TextChangedP`) MUST заменять строку ввода Claude Code в панели `CLAUDE_INPUT_PANE` полным содержимым буфера; перевод строки MUST NOT отправлять запрос.

#### Scenario: Набор текста
- **WHEN** в буфере набран текст из двух строк «первая» и «вторая»
- **THEN** строка ввода Claude Code содержит ровно эти две строки, запрос не отправлен

#### Scenario: Правка текста
- **WHEN** в буфере, содержимое которого уже передано, удаляется слово
- **THEN** строка ввода Claude Code содержит новое содержимое буфера целиком, прежнее содержимое не остаётся

### Requirement: Замена строки ввода одним запросом к сокету herdr
Замена MUST идти одним запросом `pane.send_text` к сокету herdr (`HERDR_SOCKET_PATH`) из neovim без запуска процесса и без таймеров: последовательность очистки (`i`, `ctrl+u`, Esc в кодировке `CSI 27 u`, `g g d G i`, Backspace) и текст. Текст до 700 знаков без управляющих символов, кроме перевода строки, MUST идти сырыми байтами, иначе — в рамке bracketed paste. В полёте MUST быть не больше одной отправки; изменение во время отправки MUST приводить к отправке последнего состояния после ответа.

#### Scenario: Быстрый набор
- **WHEN** пользователь набирает несколько знаков быстрее, чем приходит ответ сервера herdr
- **THEN** одновременно идёт не больше одной отправки, а после последнего ответа строка ввода совпадает с буфером

#### Scenario: Длинный текст
- **WHEN** в буфере больше 700 знаков
- **THEN** текст передаётся в рамке bracketed paste, строка ввода показывает его вставкой, а прежнее содержимое не остаётся

### Requirement: Отправка ждёт выхода Claude Code из диалога
Пока панель Claude Code в статусе `blocked`, отправка MUST откладываться и MUST выполняться по событию смены статуса из подписки herdr `pane.agent_status_changed`.

#### Scenario: Диалог Claude Code
- **WHEN** панель Claude Code в статусе `blocked` (открыт вопрос с вариантами), а буфер меняется
- **THEN** в панель Claude Code ничего не отправляется, а после смены статуса строка ввода получает последнее содержимое буфера

### Requirement: Сохранение буфера отправляет запрос
`:w` (`BufWriteCmd`) MUST одним запросом заменять строку ввода Claude Code содержимым буфера и передавать Enter, затем очищать буфер и снимать признак изменения. Пустой буфер `:w` MUST NOT отправлять. При статусе `blocked` `:w` MUST NOT отправлять и MUST NOT очищать буфер, а neovim MUST сообщать, что Claude Code ждёт ответа в диалоге.

#### Scenario: Отправка местной команды
- **WHEN** в буфере набрано `/help` и выполнено `:w`
- **THEN** Claude Code открывает справку, буфер пуст и не помечен изменённым
