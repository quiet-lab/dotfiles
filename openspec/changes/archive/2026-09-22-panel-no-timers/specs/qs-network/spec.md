## MODIFIED Requirements

### Requirement: Состояние из NetworkManager по событиям
Плитка MUST перестраивать строки только в ответ на события NetworkManager: панель держит открытым поток событий (`nmcli monitor`) и после каждого события перечитывает состояние устройств, адреса и активные VPN-соединения одним вызовом скрипта панели на основе `nmcli`. Панель MUST NOT опрашивать состояние сети по таймеру и MUST NOT держать страховочный опрос на случай пропущенных событий: единственный источник изменений — события NetworkManager. Если чтение состояния уже выполняется, когда пришло новое событие, панель MUST отложить следующее чтение до завершения текущего, не пропуская изменение и не запуская второй процесс параллельно. Модуль Quickshell для NetworkManager версии 0.3.1 не сообщает адреса IPv4 и VPN-соединения, поэтому чтение состояния через `nmcli` допускается, но только как реакция на событие.

Если процесс `nmcli monitor` завершился (например, при перезапуске NetworkManager), панель MUST запускать его заново немедленно, без паузы. Если пять запусков подряд заканчиваются мгновенным выходом (меньше секунды с момента запуска), панель MUST прекратить попытки и вывести предупреждение в журнал вместо того, чтобы перезапускать процесс по кругу без остановки.

#### Scenario: Смена сети
- **WHEN** пользователь подключается к другому wifi
- **THEN** строка WIFI показывает новый IPv4-адрес сразу после того, как NetworkManager сообщил о смене состояния, без ожидания интервала опроса

#### Scenario: Отсутствие опросов
- **WHEN** состояние сети не меняется в течение минуты
- **THEN** панель за это время не запускает ни одного процесса `nmcli`, кроме постоянно открытого потока событий, и не обращается к NetworkManager по таймеру

#### Scenario: Монитор перезапускается по выходу процесса
- **WHEN** NetworkManager перезапущен, и поток `nmcli monitor` из-за этого завершается
- **THEN** панель сразу запускает `nmcli monitor` заново, поток событий восстанавливается без вмешательства пользователя и без задержки на таймер

#### Scenario: nmcli monitor не запускается
- **WHEN** пять запусков `nmcli monitor` подряд завершаются мгновенным выходом (утилита недоступна или нет прав)
- **THEN** панель прекращает попытки запуска, пишет предупреждение в журнал и больше не пытается восстановить поток событий сама
