## MODIFIED Requirements

### Requirement: Использование RAM
Использование RAM MUST вычисляться из `/proc/meminfo` по формуле `(MemTotal − MemAvailable) / MemTotal × 100` с обновлением каждые 3 секунды. Рядом с именем шкалы MUST отображаться общий объём памяти в ГиБ (`MemTotal / 1048576`, целое число с суффиксом «G»); значение MUST браться из того же ответа скрипта `ram`, что и загрузка (то есть обновляться вместе с ней каждые 3 секунды), отдельного запроса или таймера для него быть не должно.

#### Scenario: Память исчерпана
- **WHEN** MemAvailable равно 0
- **THEN** шкала RAM показывает «100%» с классом `t-crit`

#### Scenario: Общий объём
- **WHEN** MemTotal равно 65 GiB в килобайтах
- **THEN** в заголовке шкалы RAM виден текст «65G»
