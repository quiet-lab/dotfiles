## MODIFIED Requirements

### Requirement: Подсказка в буфере диалога
Подсказка диалога MUST показываться плавающим окном (`focusable = false`) в стиле окна which-key.nvim: внизу окна буфера диалога, выровнено вправо, ширина по содержимому, рамка со скруглением и заголовок в рамке («Вопрос k из n» для вопроса карточки, «Обзор ответов» для вкладки обзора, иначе «Диалог»). Строки — «клавиша → описание» колонками: номера пунктов текущего экрана с текстом пункта (выделенный помечен `❯` и подсвечен `CursorLine`), `S-CR` и `S-Space` — подтвердить, `C-c` — отменить диалог. Подсветка — группы which-key (`WhichKey`, `WhichKeySeparator`, `WhichKeyDesc`, `WhichKeyTitle`, `WhichKeyBorder`, `WhichKeyNormal`) с запасными (`Special`, `Comment`, `Normal`, `Title`, `FloatBorder`, `NormalFloat`), если группы нет; библиотека which-key MUST NOT вызываться. Текст буфера не меняется, виртуальных строк в нём нет. Окно MUST NOT брать фокус и ввод, быть больше окна диалога (за вычетом рамки), MUST обновляться по каждому новому экрану диалога и при изменении размеров, закрываться вместе с буфером диалога и при его отмене.

#### Scenario: Вкладка обзора
- **WHEN** открыта вкладка обзора карточки
- **THEN** в правом нижнем углу окна диалога видно окно с заголовком «Обзор ответов» и строками «1 → ❯ Submit answers», «2 → Cancel», «S-CR → подтвердить», «S-Space → подтвердить», «C-c → отменить диалог», текст буфера пуст, в нём нет виртуальных строк, фокус остаётся в буфере диалога

#### Scenario: Конец диалога
- **WHEN** диалог закрыт или отменён Ctrl+C
- **THEN** окна подсказки нет
