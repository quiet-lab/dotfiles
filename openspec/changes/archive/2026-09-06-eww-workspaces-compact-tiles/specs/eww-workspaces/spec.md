# Delta: eww-workspaces

## ADDED Requirements

### Requirement: Единая раскладка плитки стола
Каждый рабочий стол MUST отображаться плиткой одинаковой формы независимо от того, активен ли он и есть ли на нём окна: слева ряд иконок приложений 20×20 (полноцветная иконка либо глиф-фолбэк), справа номер стола. Плитка MUST иметь фиксированные размеры: ширина 320px, высота 36px (ряд иконок 20px и внутренние отступы по 8px сверху и снизу). Пустой стол MUST занимать плитку того же размера только с номером.

Клик по свободному месту плитки MUST переключать на этот стол (`xdotool set_desktop`). Каждая иконка MUST быть кнопкой: клик переключает на стол окна и активирует окно (`xdotool set_desktop <стол>; xdotool windowactivate <id>`); всплывающая подсказка иконки MUST содержать название программы.

#### Scenario: Колонка не меняет высоту при переключении стола
- **WHEN** пользователь переходит с пустого стола на стол с шестью окнами
- **THEN** высота каждой плитки и всей колонки остаётся прежней

#### Scenario: Переход к окну другого стола
- **WHEN** пользователь кликает по иконке окна на неактивном столе
- **THEN** активируется этот стол и фокус получает именно это окно

#### Scenario: Переключение стола кликом по плитке
- **WHEN** пользователь кликает по плитке вне иконок
- **THEN** активным становится соответствующий стол

### Requirement: Отличия активного стола
Плитка активного стола MUST выделяться рамкой cyan (класс `ws-fo`) и более светлым цветом номера: номер активного стола отображается цветом `$foreground`, номера остальных столов — цветом `$gray`. Иных отличий в раскладке активная плитка MUST NOT иметь: список окон с подписями на ней не разворачивается.

#### Scenario: Активный стол читается по номеру
- **WHEN** дашборд отрисован
- **THEN** ровно одна плитка имеет рамку cyan и светлый номер, остальные номера серые

### Requirement: Отображение свёрнутых окон
Иконка свёрнутого окна MUST отображаться приглушённой (класс `ws-min`, полупрозрачность). Свёрнутость MUST определяться по наличию атома `_NET_WM_STATE_HIDDEN` в списке `_NET_WM_STATE` окна.

#### Scenario: Свёрнутое окно приглушено
- **WHEN** пользователь сворачивает окно на активном столе
- **THEN** после перерисовки его иконка в плитке становится полупрозрачной, остальные иконки не меняются

### Requirement: Ограничение числа иконок
Плитка MUST показывать не более 10 иконок. Если окон на столе больше, отображаются первые 10 в порядке `_NET_CLIENT_LIST` и метка «+N», где N — количество не показанных окон. При 10 и менее окнах метка MUST отсутствовать.

#### Scenario: Тринадцать окон на столе
- **WHEN** на столе открыто 13 окон
- **THEN** плитка показывает 10 иконок и метку «+3», ширина плитки остаётся 320px

## MODIFIED Requirements

### Requirement: Реактивное обновление
Скрипт MUST вывести начальное состояние и перерисовываться на каждое событие `xprop -root -spy _NET_CURRENT_DESKTOP _NET_CLIENT_LIST _NET_CLIENT_LIST_STACKING _NET_ACTIVE_WINDOW`. Число столов — `xdotool get_num_desktops`, фолбэк 8; текущий стол — `xdotool get_desktop`, фолбэк 0.

Состояние MUST передаваться в eww одной JSON-строкой на событие: список столов с номером, признаком активности, списком окон (идентификатор, путь к иконке либо глиф, признак свёрнутости, название программы) и числом не показанных окон. Разметка плитки MUST описываться в yuck-файле виджета, а не генерироваться скриптом. Если новое состояние совпадает с предыдущим выведенным, скрипт MUST NOT выводить его повторно.

#### Scenario: Переключение стола
- **WHEN** пользователь переходит на другой рабочий стол
- **THEN** рамка и светлый номер переходят к новой активной плитке, раскладка остальных плиток не меняется

#### Scenario: Сворачивание окна вызывает перерисовку
- **WHEN** пользователь сворачивает активное окно
- **THEN** колонка перерисовывается без ожидания смены стола или списка окон

### Requirement: Соответствие WM_CLASS
Таблицы соответствия MUST покрывать известные классы (firefox/Navigator, Chromium/Google-chrome, Yandex-browser*, Wezterm/org.wezfurlong.wezterm, терминалы, Neovide/nvim, TelegramDesktop, pavucontrol, nm-connection-editor, Thunar, PCManFM, Code/code-oss): имя иконки-кандидата и название программы для всплывающей подсказки. Неизвестный класс → кандидаты из нижнего регистра класса и его последнего компонента; название — последний компонент после точки.

Иконки разрешаются общим резолвером appicon; при неудаче используется Nerd Font глиф-фолбэк.

#### Scenario: Браузер
- **WHEN** WM_CLASS окна = «Navigator»
- **THEN** иконка окна — firefox, подсказка при наведении — «Firefox»

### Requirement: Экранирование вывода
Строковые значения в JSON (название программы, путь к иконке, глиф) MUST экранироваться: `\` → `\\`, `"` → `\"`, управляющие символы удаляются. Внутренний разделитель полей скрипта MUST быть управляющим символом, который удаляется из значений при экранировании, чтобы он не мог встретиться в данных.

#### Scenario: Кавычки в заголовке окна
- **WHEN** название программы или путь к иконке содержит символ `"`
- **THEN** выведенный JSON остаётся корректным и eww отрисовывает плитку

## REMOVED Requirements

### Requirement: Активный стол
**Reason**: Развёрнутый список окон с подписями на активном столе заменён единой раскладкой плитки; отличия активного стола вынесены в отдельное требование.
**Migration**: Переход к конкретному окну выполняется кликом по его иконке в плитке; название программы доступно во всплывающей подсказке.

### Requirement: Занятые неактивные столы
**Reason**: Поведение поглощено требованием «Единая раскладка плитки стола», которое действует для всех столов без разделения на активные и неактивные.
**Migration**: Не требуется, внешний вид занятых неактивных столов сохраняется с переносом номера вправо.
