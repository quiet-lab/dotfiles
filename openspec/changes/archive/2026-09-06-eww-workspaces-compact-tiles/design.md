## Context

Виджет `workspaces` — единственный в дашборде, чей скрипт генерирует готовую yuck-разметку и отдаёт её в `(literal)`. Остальные ограничения, определяющие решение:

- eww умеет разворачивать массивы через `(for x in {array} ...)`, в том числе вложенно, и обращаться к полям JSON-объектов (`{x.field}`); условия задаются через `:visible` и тернарные выражения.
- `deflisten` принимает произвольную строку; если она разбирается как JSON, поля доступны в выражениях без дополнительной обработки.
- Свойство `_NET_WM_STATE` окна — список атомов; сворачивание отражается атомом `_NET_WM_STATE_HIDDEN` внутри него, отдельного свойства с таким именем не существует.
- Проверено на живой системе: сворачивание окна не меняет `_NET_CLIENT_LIST` и не всегда меняет `_NET_CLIENT_LIST_STACKING` (при сворачивании нефокусного окна события нет вовсе). Разворачивание и поднятие окна меняют `_NET_CLIENT_LIST_STACKING`. Сворачивание активного окна переводит фокус и меняет `_NET_ACTIVE_WINDOW`.
- GTK box не переносит содержимое на новую строку; ширина колонки 320px фиксирована спецификацией `eww-shell`.
- Вложенные кнопки в GTK допустимы: клик по внутренней кнопке не доходит до внешней.

## Goals / Non-Goals

**Goals:**

- Разметка плитки целиком в `workspaces.yuck`, скрипт отвечает только за сбор состояния.
- Постоянный размер колонки при любом состоянии столов.
- Корректное отображение свёрнутых окон и перерисовка по событиям сворачивания.

**Non-Goals:**

- Показ заголовков окон (`_NET_WM_NAME`) и слежение за их изменением.
- Подсветка активного окна внутри плитки (`_NET_ACTIVE_WINDOW`).
- Скрытие пустых столов и чтение имён столов из `_NET_DESKTOP_NAMES`.
- Изменение резолвера `scripts/appicon` и таблиц соответствия WM_CLASS.

## Decisions

### 1. JSON-состояние и `for` в yuck вместо генерации разметки

Скрипт выводит одну строку JSON вида:

```
{"desktops":[
  {"n":1,"active":false,
   "windows":[{"id":29360131,"icon":"/usr/share/icons/.../firefox.svg","glyph":"","min":false,"name":"Firefox"}],
   "more":0},
  ...
]}
```

В yuck: внешний `for` по `desktops`, внутренний по `windows`; выбор между `image` и `label`-глифом делается через `:visible` по непустому `icon`; метка «+N» видима при `more > 0`; классы `ws-fo` и `ws-min` подставляются тернарными выражениями.

Альтернатива — оставить `literal` и переписать shell-склейку под новую раскладку. Отвергнута: каждая правка внешнего вида снова потребует править экранированные строки, а условия вроде «первые 10 и метка» в shell читаются хуже, чем в yuck. Производительность обоих вариантов одинакова: eww пересоздаёт дерево при любом изменении значения.

### 2. Ограничение числа иконок выполняет скрипт

Скрипт обрезает массив `windows` до 10 элементов и записывает число оставшихся в поле `more`. В eww нет удобной операции взятия среза массива, а условие по индексу внутри `for` усложнило бы разметку. Порядок окон — порядок `_NET_CLIENT_LIST` (порядок появления окон), он стабилен и не меняется при смене фокуса.

### 3. Фиксированный размер через min-размеры содержимого

В GTK CSS `min-height` и `min-width` относятся к области содержимого без учёта внутренних отступов. Для плитки 320×36 при `padding: 8px 10px` задаются `min-width: 300px` и `min-height: 20px` на `.ws`. Ряд иконок получает `:hexpand true`, номер — `:halign "end"`, поэтому номер прижат к правому краю и при пустом ряде.

Альтернатива — задать пустой плитке невидимую иконку-распорку. Отвергнута как обходной приём: min-размеры решают задачу напрямую.

### 4. Кнопки внутри плитки

Плитка — `eventbox` с `:onclick "xdotool set_desktop N"`, иконки внутри — `button` с собственным `:onclick`. Клик по иконке не доходит до `eventbox`, клик по свободному месту переключает стол. Подсказка `:tooltip` с названием программы ставится на кнопку-иконку.

### 5. Определение свёрнутости и дополнительный триггер

Свёрнутость: `xprop -id <окно> _NET_WM_STATE`, признак — наличие подстроки `_NET_WM_STATE_HIDDEN`. Чтобы перерисовка происходила при сворачивании и разворачивании, в `xprop -root -spy` добавляются `_NET_CLIENT_LIST_STACKING` (разворачивание, поднятие) и `_NET_ACTIVE_WINDOW` (сворачивание активного окна, при котором фокус уходит на другое окно). Сворачивание нефокусного окна программным способом (например, `xdotool windowminimize` по идентификатору) не даёт ни одного события на корневом окне и отражается только при следующей перерисовке; в обычной работе пользователь сворачивает окно, которое перед этим получило фокус. Плата — перерисовка при каждой смене фокуса и поднятии окна; она компенсируется решением 6.

### 6. Подавление одинаковых состояний

Скрипт хранит последнюю выведенную строку и печатает новую только при отличии. Смена фокуса между окнами без изменения столов и свёрнутости даёт тот же JSON и не приводит к пересозданию дерева в eww.

### 7. Внутренний формат записей скрипта

Функция `collect` разделяет поля управляющим символом US (0x1F) вместо `|`. Табуляция для этого не подходит: в `read` она относится к пробельным разделителям, и пустые поля (например, глиф при найденной иконке) схлопывались бы. JSON-экранирование (`\`, `"`, удаление всех управляющих символов, включая US) выполняется функцией `jesc` ещё в `collect`, поэтому в записях разделитель встретиться не может, а `render` подставляет значения без повторной обработки. Внешние утилиты для JSON (`jq`) не подключаются, чтобы не добавлять зависимость ради двух уровней вложенности.

## Risks / Trade-offs

- [Openbox не обновляет `_NET_CLIENT_LIST_STACKING` при сворачивании нефокусного окна] → Подтверждено проверкой; добавлен запасной триггер `_NET_ACTIVE_WINDOW`, покрывающий сворачивание активного окна. Программное сворачивание нефокусного окна остаётся вне охвата до следующего события.
- [Кнопки-иконки 20×20 мелкие для клика] → Внутренний отступ кнопки 2px даёт область 24×24 без роста высоты плитки; при неудобстве размер иконки можно поднять до 24px за счёт уменьшения лимита.
- [Ошибка в JSON ломает всю колонку, а не одну плитку] → Начальное значение `deflisten` задаётся валидным пустым состоянием; экранирование покрыто требованием спецификации и проверяется на окне с кавычкой в названии.
- [Пользователь теряет названия окон в колонке] → Осознанное решение проекта; название сохранено во всплывающей подсказке.

3. Откат: `chezmoi apply` из предыдущего коммита или `git checkout` трёх файлов виджета и повторный `eww reload`; общие файлы не затрагиваются.
