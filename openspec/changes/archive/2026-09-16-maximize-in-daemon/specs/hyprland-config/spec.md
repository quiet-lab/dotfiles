## MODIFIED Requirements

### Requirement: Фокус кликом и рамка активного окна
Фокус окна MUST переходить только по клику в области окна: наведение курсора фокус не переводит, в том числе при переходе между плавающими окнами. Курсор MUST NOT переноситься к окну при смене фокуса диспетчером (активация из плитки стола, Alt+Tab). Рамка окна MUST быть шириной 1 px, как рамка плиток панели; рамка активного окна MUST быть цвета рамки плиток панели (yellow Tokyo Night `#E0AF68`), рамка неактивного окна — приглушённой. Слои с клавиатурой по требованию (поле фильтра панели) MUST NOT удерживать клавиатуру при клике по окну (`misc.layers_hog_keyboard_focus` выключен).

#### Scenario: Наведение не меняет фокус
- **WHEN** в фокусе терминал, а курсор проходит над окном браузера без клика
- **THEN** фокус клавиатуры остаётся у терминала, браузер не поднимается над ним

#### Scenario: Активация из панели без переноса курсора
- **WHEN** пользователь кликает по иконке окна в плитке стола
- **THEN** окно получает фокус и поднимается наверх, а курсор остаётся на панели

#### Scenario: Цвет рамки
- **WHEN** окно в фокусе
- **THEN** его рамка жёлтая `#E0AF68` шириной 1 px, как рамки плиток панели; `hyprctl getoption general:border_size` показывает 1
