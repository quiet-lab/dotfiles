# Tasks: Автозапуск EWW-дашборда в Openbox

## 1. Правка автостарта

- [x] 1.1 Добавить в конец `dot_config/openbox/autostart.sh` фоновый блок запуска по design D2/D3: проверка `[ -x "$(command -v eww)" ]`, защита от дублей демона `pidof -s eww -q || eww daemon`, затем `eww open dashboard`. Проверить синтаксис: `sh -n dot_config/openbox/autostart.sh` без ошибок.
- [x] 1.2 Убедиться, что блок не нарушает остальной скрипт: запустить копию файла с подменённым `PATH` (без eww) — выход молча, код 0, остальные строки до правки отрабатывали и раньше (см. сценарий «Отсутствует бинарник eww»).

## 2. Деплой через chezmoi

- [x] 2.1 Выполнить `chezmoi apply` и проверить, что блок присутствует в цели: `rg -n "eww" ~/.config/openbox/autostart.sh`.

## 3. Проверка сценариев спеки

- [x] 3.1 Сценарий «Вход в сессию»: в живой сессии выполнить целевой скрипт один раз (`sh ~/.config/openbox/autostart.sh`) — `pidof -s eww` возвращает PID, `eww list-windows` показывает `dashboard`, колонка видима у левого края.
- [x] 3.2 Сценарий «Перезапуск Openbox не дублирует дашборд»: повторить запуск скрипта и/или выполнить `openbox --restart` — демон по-прежнему один (`pidof -s eww` — один PID), окно `dashboard` в единственном экземпляре (`eww windows`).
- [x] 3.3 Сценарий «Отсутствует бинарник eww»: запустить скрипт с `PATH` без каталога eww — команда завершается молча, остальные компоненты сессии продолжают работать.
