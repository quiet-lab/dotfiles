## MODIFIED Requirements

### Requirement: Состав и геометрия плиток
Панель MUST отображать колонку плиток с составом, порядком и координатами из таблицы ниже (левый отступ 10 px, зазор между плитками 10 px, расчёт под экран 3840×2160). Полный ряд имеет ширину 320 px; если не указано иное, x = 10 px и ширина 320 px:

| Плитка | y | Особенности |
|--------|---|-------------|
| питание: блокировка, выход, перезапуск, перезагрузка, выключение | 10 px | x = 10/76/142/208/274 px, квадраты 56×56 px в один ряд |
| часы с датой и календарём | 76 px | высота 239 px |
| погода | 325 px | высота 215 px |
| шкалы CPU, RAM, GPU | 680 px | x = 10/120/230 px, ширина 100 px |
| сеть | 792 px | |
| диски | 909 px | |
| избранное | 1154 px | |
| рабочие столы 1…8 | 1416 px + 46 px·(n−1), плюс 46 px для столов ниже активного | по плитке на стол: 274×36 px, у активного стола 274×82 px; блок 404 px |
| уведомления | 1416 px | x = 294 px, 36×36 px (на уровне первого стола, над треем) |
| трей | 1462 px | x = 294 px, 36×312 px (вертикальный, справа от столов) |
| раскладка | 1784 px | x = 294 px, 36×36 px (вровень с нижним краем восьмого стола) |
| лаунчер | 1830 px | 320×320 px (квадрат у нижнего края) |

Колонка MUST занимать монитор по вертикали целиком (10…2150 px) тремя группами: вверху — ряд питания, часы и погода (10…540 px); внизу — лаунчер у нижнего края (1830…2150 px), а над ним через зазор 10 px блок рабочих столов с правой колонкой 36 px из уведомлений, трея и раскладки (1416…1820 px, высота блока постоянна, так как двойной высоты всегда ровно одна плитка активного стола); средняя группа (шкалы, сеть, диски, избранное, всего 597 px) MUST стоять по центру свободного промежутка между верхней и нижней группами (отступы 140 px сверху и 139 px снизу). При изменении высоты какой-либо плитки координаты MUST быть пересчитаны: нижняя группа привязана к нижнему краю, средняя центрируется заново.

#### Scenario: Порядок и координаты фиксированы
- **WHEN** панель запущена
- **THEN** плитки следуют в порядке из таблицы без пропусков, каждая занимает указанные координаты и размеры, между соседними плитками зазор 10 px

#### Scenario: Геометрия колонки
- **WHEN** на снимке экрана сессии измерены положения и размеры плиток
- **THEN** границы всех плиток совпадают с точностью до пикселя
