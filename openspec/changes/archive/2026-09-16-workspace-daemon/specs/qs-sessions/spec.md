## Purpose

Окно выбора сессии в панели Quickshell: список сохранённых сессий демона workspaced с картой «стол → workspace» и загрузка выбранной.

## ADDED Requirements

### Requirement: Окно выбора сессии
По событию `show-sessions` от демона панель MUST открыть всплывающее окно справа от колонки плиток со списком сессий (имя, время снимка), сессия `default` первая. При перемещении по списку стрелками или наведением справа MUST показываться карта выбранной сессии: для каждого стола список workspace, активный выделен, у workspace активного стола пометка «сразу», у остальных активных «при переходе», у прочих «по вызову». Enter или клик MUST загружать выбранную сессию через демон и закрывать окно; Escape и клик вне окна MUST закрывать без действия. Окно MUST принимать клавиатуру только пока открыто и отпускать её при закрытии, чтобы окно, бывшее в фокусе, снова принимало ввод. Поле ввода имени внизу списка с Enter MUST сохранять текущее состояние под введённым именем.

#### Scenario: Открытие и карта
- **WHEN** нажата цепочка `sessions` при сохранённых `default` и `review`
- **THEN** появляется окно со списком из двух сессий, выделен `default`, справа карта его столов; стрелка вниз показывает карту `review`

#### Scenario: Загрузка
- **WHEN** в окне выбран `review` и нажат Enter
- **THEN** окно закрывается, демон загружает `review`, фокус возвращается окну приложения

#### Scenario: Сохранение из окна
- **WHEN** в поле имени введено `front-day` и нажат Enter
- **THEN** появляется сессия `front-day`, список обновляется, окно остаётся открытым

#### Scenario: Отмена
- **WHEN** окно открыто и нажат Escape
- **THEN** окно закрывается, состояние не меняется, терминал, бывший в фокусе, принимает ввод
