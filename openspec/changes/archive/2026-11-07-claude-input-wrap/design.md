# Design: Перенос строк в окне буфера ввода

## Решение

Перенос задаётся оконными опциями (`wrap`, `linebreak` — перенос по словам,
`breakindent`), а не вставкой символов переноса: текст буфера и то, что уходит
в строку ввода Claude Code, остаются прежними.

Опции ставит сверка окон по событию `BufWinEnter` любого буфера: окно
текущим может не быть, поэтому проверяются все окна. У окна с буфером модуля
опции включаются, у окна, из которого буфер ушёл, возвращаются прежние значения
(окно, созданное делением окна модуля, возвращается к значению по умолчанию).
Соседние буферы настройку не наследуют. Глобальные опции не меняются.
