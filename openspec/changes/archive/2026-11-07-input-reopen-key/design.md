# Design: Клавиша переоткрытия панели ввода

## Поиск панели Claude

Одна функция `find_claude_pane` хука, только для режима `reopen`; режимы `open`
и `close` вызывают хуки Claude Code с `HERDR_PANE_ID` панели Claude и не
меняются. Порядок: у панели из `HERDR_PANE_ID` есть токен `input_pane` (это
панель Claude); токен `input_pane` панели агента того же workspace равен
`HERDR_PANE_ID` (вызов из панели буфера); панель сама — агент Claude без
панели буфера; единственная панель агента Claude workspace с токеном, а без
токена — единственная вообще. Не нашли — сообщение в stderr и код 1.
Дальше хук работает с найденной панелью как с `HERDR_PANE_ID`: файл
соответствия, токен и деление относятся к ней.

## Проверка предков

Команду клавиши запускает сервер herdr, среди его предков нет `claude`, поэтому
проверка предка с терминалом, нужная `open` и `close` против вложенного
`claude -p`, для `reopen` снята: режим вызывает пользователь.
