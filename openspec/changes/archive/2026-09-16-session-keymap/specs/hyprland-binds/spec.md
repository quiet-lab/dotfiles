## ADDED Requirements

### Requirement: Раскладка клавиш сессии
Конфиг демона workspaced (`~/.config/workspaced/config.toml`: разделы `[keys]`, цепочки workspace и приложений, записи `[[binds]]`) MUST задавать все привязки сессии; `hyprland.lua` MUST NOT содержать собственных привязок, кроме загрузки кода привязок от демона. Раскладка строится от понятий демона: префикс Super+Tab для действий с workspace, слой Alt+Super для геометрии окна, Super+буква для действий с окном и программами:

| Сочетание | Действие |
|---|---|
| Super+Tab d / w / c | поднять workspace dots / workspaced / chat на текущем столе (цепочки workspace) |
| Super+Tab 1…8 <буква> | перейти на стол и поднять там workspace с этой буквой |
| Super+Tab s | сохранить активный workspace в конфиг |
| Super+Tab Tab | поднять следующий workspace из списка текущего стола |
| Super+A b / e / f / m / t | сделать главным приложение firefox / редактор / thunar / telegram / терминал (цепочки приложений) |
| Super+S | окно выбора сессии |
| Super+Return | запуск `wezterm-gui` |
| Super+R | лаунчер `rofi -show drun` |
| Super+E | файловый менеджер thunar |
| Super+C | закрыть активное окно |
| Super+V | меню буфера обмена (история cliphist через rofi, выбранная запись вставляется в буфер) |
| Super+F | переключить полноэкранный режим |
| Super+X | переключить развёртывание окна командой демона `maximize`: окно занимает рабочую область с отступом 10 px от краёв экрана и панели, тем же, что у половин и плиток панели; повторное нажатие возвращает прежние положение и размер |
| Super+Shift+V | переключить плавающий режим окна |
| Super+Z | спрятать активное окно в специальный рабочий стол без перехода за ним |
| Super+Shift+Z | показать или скрыть специальный рабочий стол со спрятанными окнами |
| Super+стрелки | перенести фокус на соседнее окно в направлении стрелки |
| Alt+Super+Влево / Вправо | активное окно занимает левую / правую половину рабочей области командой демона `half` с отступом 10 px от краёв и между окнами, тем же, что между плитками панели |
| Alt+Super+Вверх / Вниз | активное окно занимает верхнюю / нижнюю половину рабочей области с теми же отступами |
| Alt+Super+Home / PageDown / End | активное окно в половину ширины и высоты рабочей области в верхнем ряду слева / по центру / справа командой демона `place` с теми же отступами |
| Ctrl+Alt+Super+Z / X / V | то же в нижнем ряду слева / по центру / справа |
| Ctrl+Alt+Super+C | активное окно в половину ширины на всю высоту по центру |
| Alt+Super+PageUp | активное окно на всю рабочую область с отступами (без возврата прежней геометрии) |
| Alt+Super+Menu | переключить полноэкранный режим, как Super+F |
| Super+1…8 | перейти на рабочий стол 1…8 |
| Super+Shift+1…8 | перенести активное окно на стол 1…8 и перейти вслед за ним |
| Alt+Tab, Alt+Shift+Tab | переключить фокус на следующее / предыдущее окно текущего стола с подъёмом окна наверх |
| Super+L | заблокировать сессию командой `loginctl lock-session` |
| Super+M | выход из сессии |
| Super+Shift+C | переключение аппаратного и программного курсора |
| Print, Ctrl+Print, Shift+Print | скриншот экрана, с обратным отсчётом, области |
| Ctrl+Escape, Ctrl+Return, Ctrl+Пробел, Ctrl+Shift+Пробел | dunstctl history-pop, context, close, close-all |
| XF86AudioRaiseVolume / LowerVolume / Mute | `~/.scripts/change-volume.sh` с аргументами `+`, `-`, `0` |
| XF86MonBrightnessUp / Down | `~/.scripts/change-brightness.sh` с аргументами `+`, `-` |
| XF86AudioPlay / Stop / Prev / Next | playerctl play-pause, stop, previous, next |
| Super+левая кнопка мыши | перемещение окна перетаскиванием |
| Super+правая кнопка мыши | изменение размера перетаскиванием |

Сочетания Super+Shift+стрелки MUST оставаться свободными. Рабочая область — площадь монитора за вычетом зон, зарезервированных слоями (панелью).

#### Scenario: Префикс workspace
- **WHEN** нажато Super+Tab, затем d
- **THEN** на текущем столе поднимается workspace dots, подкарта закрывается; `hyprctl binds` содержит подкарту, открываемую Super+Tab, и не содержит одиночного действия на Super+Tab

#### Scenario: Следующий workspace
- **WHEN** на столе два workspace и нажато Super+Tab, затем Tab
- **THEN** поднимается следующий workspace из списка стола

#### Scenario: Окно в половину рабочей области
- **WHEN** при активном плавающем окне нажато Alt+Super+Влево, зарезервированных зон нет, `gap = 5`
- **THEN** окно получает положение 10,10 и размер 1905×2140 на мониторе 3840×2160

#### Scenario: Окно в позицию рабочей области
- **WHEN** при активном плавающем окне нажато Ctrl+Alt+Super+V, затем Ctrl+Alt+Super+C, панель резервирует 330 px слева, `gap = 5`
- **THEN** окно получает положение 2090,1085 и размер 1740×1065, затем 1215,10 и 1740×2140

#### Scenario: Развёрнутое окно с отступами
- **WHEN** при активном плавающем окне нажато Super+X, панель резервирует 330 px слева на мониторе 3840×2160, `gap = 5`
- **THEN** окно получает положение 340,10 и размер 3490×2140, а повторное нажатие Super+X возвращает ему прежние положение и размер

#### Scenario: Перенос окна на стол
- **WHEN** при активном окне нажато Super+Shift+3
- **THEN** окно оказывается на столе «3», стол «3» становится активным, окно остаётся в фокусе

#### Scenario: Блокировка
- **WHEN** нажато Super+L
- **THEN** экран закрывает hyprlock, после ввода пароля сессия продолжается со всеми окнами

#### Scenario: Привязок в конфиге Hyprland нет
- **WHEN** выполнен поиск `hl.bind` в `~/.config/hypr/hyprland.lua`
- **THEN** совпадений нет, а `hyprctl binds` содержит все сочетания из таблицы

### Requirement: Зарезервированные сочетания
Список `reserved` раздела `[keys]` конфига демона MUST содержать сочетания, которые ни одна привязка занимать не может, с комментарием о причине: сочетания карты XKB Super+Пробел, Alt+E и Alt+R, которые композитор перехватил бы раньше XKB, и намеренно свободные Alt+Пробел, Alt+Super+Пробел, Super+T и Super+D. Проверка конфига MUST отклонять привязку на любое из этих сочетаний, а конфиг MUST NOT назначать их действиям без отдельного решения.

#### Scenario: Сочетание без действия
- **WHEN** нажато Super+T
- **THEN** ничего не происходит, `hyprctl binds` не содержит этого сочетания

#### Scenario: Попытка занять зарезервированное сочетание
- **WHEN** в `[[binds]]` добавлена запись с `chain = "SUPER+D"` и выполнена `workspaced check`
- **THEN** команда завершается с ошибкой, называющей `SUPER+D` как зарезервированное, демон продолжает работать с прежним конфигом

## REMOVED Requirements

### Requirement: Соответствие привязкам Openbox
**Reason**: Openbox удалён из системы; раскладка сессии строится от понятий демона workspaced, а не от `rc.xml`.
**Migration**: Привязки описаны требованием «Раскладка клавиш сессии»; сочетания Super+W … заменены на Super+Tab …, Super+Shift+стрелки — на Alt+Super+стрелки.

### Requirement: Привязки, не переносимые из Openbox
**Reason**: Список зарезервированных сочетаний больше не привязан к Openbox.
**Migration**: Тот же список описан требованием «Зарезервированные сочетания».
