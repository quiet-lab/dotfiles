## Причина

Живая проба Claude Code v2.1.319 (`AskUserQuestion` из двух вопросов, первый — множественный выбор) показала экран с теми же строками, что у последнего вопроса, но кнопка названа «Next»:

```
❯ 1. [ ] Яблоко
  …
  4. [ ] Type something
     Next
  5. Chat about this
```

`numbered_rows` в `dialog.lua` искала только строку «Submit»; без неё в `rows` не было позиции кнопки, и `submit_keys` отправлял Enter на выделенном пункте. Экран снят в `tests/fixtures/ask-q1-multi-next.txt`.

## Решение

Надписи кнопки — множество {«Submit», «Next»} на том же месте (ненумерованная строка между пунктом свободного ввода и «Chat about this»). Надпись хранится в `label` строки, образец выделения `selected_regex` строится по ней. Остальная логика (цифры, вкладки, обзор) не меняется. Опроса и таймеров нет: разбор по-прежнему идёт по событиям подписок herdr.
