## ADDED Requirements

### Requirement: Индикатор цепочки с выходом
Панель Quickshell MUST показывать индикатор, пока открыта цепочка с выходом (спецификация ws-config, «Цепочки с выходом»). Состояние индикатора MUST определяться событием Hyprland `submap`: имя подкарты с префиксом `ws-sticky:` показывает индикатор для этого состояния, пустое имя и любое другое имя скрывают его. Опрашивать композитор или демон по времени панель MUST NOT.

#### Scenario: Вход, переход и выход
- **WHEN** выполнена `hyprctl eval 'hl.dispatch(hl.dsp.submap("ws-sticky:apps"))'`, затем то же для `ws-sticky:apps/raise`, затем `hl.dsp.submap("reset")`
- **THEN** `qs -c panel ipc call chains state` после первого вызова начинается с «shown ws-sticky:apps», после второго — «shown ws-sticky:apps/raise» с числом строк, равным числу клавиш состояния в `keys --json`, после третьего — «hidden»; слой индикатора в `hyprctl layers` есть только пока карточка показана

#### Scenario: Подкарта без префикса индикатора не показывает
- **WHEN** открыта подкарта `ws:SUPER + TAB`
- **THEN** `qs -c panel ipc call chains state` печатает «hidden»

### Requirement: Индикатор после перезапуска панели
При старте панель MUST один раз прочитать текущую подкарту (`hyprctl submap`), чтобы после перезапуска панели внутри цепочки индикатор был на месте.

#### Scenario: Перезапуск панели внутри цепочки
- **WHEN** открыта подкарта `ws-sticky:apps/spawn` и панель перезапущена
- **THEN** после запуска панели `qs -c panel ipc call chains state` начинается с «shown ws-sticky:apps/spawn»

### Requirement: Карточка индикатора
Индикатор MUST быть карточкой в оформлении плиток панели на слое Overlay в правом нижнем углу экрана: правый и нижний края карточки отстоят от краёв экрана на 10 px. Карточка MUST NOT брать клавиатуру и MUST NOT принимать ввод мыши: нажатия обрабатывает композитор, клики проходят к окнам под ней. Ширина карточки MUST определяться содержимым.

#### Scenario: Карточка не мешает вводу
- **WHEN** цепочка `apps` открыта в состоянии «Поднять» и пользователь нажимает V
- **THEN** окно Chrome AI.dev2026 поднимается, карточка остаётся на экране, путь «Приложения ▸ Поднять» не меняется; активным окном остаётся поднятое окно Chrome, а не слой панели

### Requirement: Содержимое карточки индикатора
В карточке MUST быть путь подписей состояний от корня через « ▸ » («Приложения ▸ Поднять»), клавиши текущего состояния строками «клавиша — описание» с пометкой клавиш выхода и нижняя строка «Backspace — назад · Escape — выход» (в корне — «Backspace — выход · Escape — выход»).

#### Scenario: Состояние «Поднять»
- **WHEN** открыта цепочка `apps` в состоянии «Поднять»
- **THEN** карточка показывает путь «Приложения ▸ Поднять», по строке «клавиша — описание» на каждую клавишу состояния, у клавиши E — пометку выхода, а внизу — «Backspace — назад · Escape — выход»; в корне цепочки нижняя строка — «Backspace — выход · Escape — выход»

### Requirement: Клавиши и подписи индикатора
Клавиши и подписи MUST браться из раздела `sticky` вывода `~/.local/bin/workspaced keys --json`, найденного по имени подкарты. Команда MUST запускаться при входе в цепочку (событие с префиксом `ws-sticky:` после имени без него) и при старте панели внутри цепочки; переходы между состояниями открытой цепочки MUST обходиться без запуска команды.

#### Scenario: Переходы без запуска команды
- **WHEN** нажато Super+S, затем R, Backspace и S
- **THEN** `workspaced keys --json` запускается один раз, при входе в цепочку; после каждого перехода `qs -c panel ipc call chains state` показывает подкарту нового состояния и число его клавиш из того же вывода

### Requirement: Карточка без вывода команды
Пока команда `workspaced keys --json` выполняется, а также если она завершилась ошибкой или состояния с таким именем подкарты в её выводе нет, карточка MUST показывать путь из имени подкарты (имена состояний через « ▸ ») и, при ошибке, текст ошибки.

#### Scenario: Ошибка команды
- **WHEN** после запуска панели `workspaced keys --json` ещё ни разу не завершилась успешно и при первом входе в цепочку `apps` завершается с ненулевым кодом
- **THEN** карточка показывает путь «apps» из имени подкарты без строк клавиш и текст ошибки: вывод команды в stderr, а без него — код выхода; `qs -c panel ipc call chains state` начинается с «shown ws-sticky:apps rows=0» и содержит «error=»

### Requirement: Состояние индикатора по IPC
Панель MUST объявлять IPC-цель `chains` с функцией `state`: строка «hidden» либо «shown <имя подкарты> rows=<число строк клавиш> card=x,y WxH».

#### Scenario: Индикатор скрыт
- **WHEN** ни цепочка с выходом, ни другая подкарта не открыта
- **THEN** `qs -c panel ipc call chains state` печатает «hidden»
