## Context

Подписка Amnezia Premium хранится в хранилище приложения
`~/.config/AmneziaVPN.ORG/AmneziaVPN.conf` (`api_config`:
`available_countries`, `user_country_code`, `server_country_code`,
`auth_data`). Приложение при смене страны отправляет шлюзу
`gw.amnezia.org` запрос `POST /v1/config` и получает конфиг AWG новой
страны. `amn0` собирается из конфига приложения сценарием
`amn-export-config` по шаблону `amn0.conf.template` и поднимается
`awg-quick@amn0` в amneziawg-go (модуля ядра нет). Правило проекта —
только события, без таймеров и опроса (запись 0007).

## Goals / Non-Goals

**Goals:** видеть и менять страну `amn0` из панели без пароля; видеть
отсутствие связи у поднятого туннеля.

**Non-Goals:** правка хранилища приложения; правка профиля `axata`;
проверка связи пробными запросами.

## Decisions

- **Запрос к шлюзу повторяется, а не переносится конфиг из приложения.**
  Протокол восстановлен по клиенту 5.0.3.0: ключ AES-256-CBC и IV
  шифруются открытым ключом RSA шлюза (PKCS#1 v1.5), тело запроса —
  AES; ответ — AES тем же ключом, конфиг `vpn://` (base64url
  от qCompress). Открытый ключ шлюза берётся из исполняемого файла
  приложения (`/opt/AmneziaVPN/bin/AmneziaVPN`): в нём два ключа PEM,
  подходящий определяется успешной расшифровкой ответа. Так ключ
  обновляется вместе с приложением. Ключевая пара клиента новая на каждый
  запрос (`awg genkey`). Вариант «перенести конфиг из приложения» отвергнут:
  требует ручной смены страны в приложении.
- **Разделение прав.** Запрос, расшифровка и сборка — пользовательский
  `amn-country` (секреты подписки читаются из хранилища пользователя).
  Установка — `amn-apply-config` от root: JSON `{code, name, config}`
  на стандартном вводе (не больше 64 КиБ), проверка кода, названия и
  разделов конфига по шаблону, блокировка `flock`, копии `.prev`,
  перезапуск и проверка страны выхода `curl --interface amn0`, откат при
  неудаче. В sudoers сценарий разрешён только без аргументов (`""`),
  поэтому через правило нельзя передать путь к чужому файлу.
- **Своё состояние `country.json`, хранилище приложения не меняется.**
  `/etc/amnezia/country.json` хранит код и название выбранной страны;
  `amn-export-config` при выгрузке из приложения удаляет его, а
  `install.sh` при наличии файла выгрузку пропускает, чтобы повторная
  установка не вернула страну приложения. Приложение при подключении
  может перевыпустить ключ и сделать конфиг панели недействительным —
  в документации записано: не подключаться в приложении.
- **Ключи AWG 2.0.** Шлюз выдаёт HeaderProtectionKey, RekeyAfterTime,
  RekeyTimeout, RejectAfterTime, KeepaliveTimeout, MaxHandshakeAttempts,
  ContentPaddingAddition; amneziawg-tools 3.1 их понимает, они добавлены
  в разрешённые ключи `amn-export-config`.
- **Страна выхода — один запрос ipinfo.io через `amn0` при открытии окна**
  сведений, как остальные сведения окна; не опрос.
- **Связь amn0 по журналу amneziawg-go.** Drop-in
  `awg-quick@amn0.service.d/50-log-verbose.conf` задаёт
  `LOG_LEVEL=verbose`; демон тогда оставляет вывод в журнале службы.
  Порог «связи нет» — третья попытка рукопожатия (около 10 с без ответа):
  одна повторная попытка бывает и при живом сервере. «giving up» —
  связи нет сразу. Ответ на рукопожатие или keepalive от сервера снимают
  признак. Собственные отправки и служебные строки (`Routine`, `UAPI`)
  состояние не меняют.
- **PersistentKeepalive в шаблон не добавляется.** Конфиги шлюза уже
  содержат `PersistentKeepalive = 25`, и `amn-export-config` переносит
  его из раздела Peer; при простое keepalive раз в 25 с дают «Receiving
  keepalive packet» и рукопожатия, по которым видна потеря связи.
- **Связь axata по журналу `nm-openvpn`.** «Inactivity timeout»,
  «SIGUSR1[soft», «Connection reset», «TLS Error», «No route to host»,
  «Network is unreachable» — связи нет; «Initialization Sequence
  Completed» — есть. В профиле `axata` нет `ping`/`ping-restart`, и
  OpenVPN работает с `--verb 1`; придут ли «Inactivity timeout» без
  опций от сервера, неизвестно — профиль не меняется, вопрос вынесен
  в отчёт.
- **Признак связи хранится в панели**, а не в `tunnelstate`: сценарий
  перечитывает состояние по событиям и признак не знает; при слиянии
  признак сохраняется, пока туннель поднят.
- **Знак анархии — элемент Shape по геометрии SVG.** Глиф Ⓐ шрифтов
  (Iosevka, Noto Sans Symbols) — буква в круге, а не знак анархии, и
  выглядит плохо. Взят файл Wikimedia Commons «Anarchy-symbol.svg»
  (общественное достояние, круг и путь штрихом), он лежит в
  `icons/anarchy.svg` как образец. Рисует его `Shape` с `PathAngleArc` и
  `PathSvg` в координатах 620×620, масштабированный до 20 px: цвет
  штриха берётся из `Theme` привязкой, как у глифов. Отвергнуты: `Image`
  с `MultiEffect` (перекраска полупрозрачных краёв штриха неточна, лишний
  проход отрисовки) и файл на каждый цвет (дублирует цвета `Theme`).
  Штрих 62 единицы = 2 px совпадает по весу с глифом `axata`, проверено
  снимком экрана; `Shape` уже используется в панели (`Gauges.qml`).

## Risks / Trade-offs

- Шлюз мог отозвать ключ прежнего конфига после выдачи нового → откат
  вернёт неработающий конфиг; тогда значок покажет ошибку, страна
  выбирается заново.
- Протокол шлюза не документирован и может измениться с новым клиентом
  → `amn-country` завершится ошибкой, туннель не трогается.
- Подробный журнал amneziawg-go пишет строку на каждый keepalive (раз
  в 25 с) — объём журнала растёт незначительно.
