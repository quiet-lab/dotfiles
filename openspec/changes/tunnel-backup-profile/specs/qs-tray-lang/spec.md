## MODIFIED Requirements

### Requirement: Значки туннелей
Сверху трея, над значками StatusNotifierItem, MUST стоять значки туннелей на постоянных местах: AmneziaWG `amn0` — силуэт символа Amnezia одним цветом (символ логотипа клиента AmneziaVPN без надписи, `icons/amnezia.js`, источник и лицензия — `icons/README.md`), под ним OpenVPN `axata` (глиф 󰦝); размер 20 px, шаг 6 px. `amn0` поднят, когда служба `awg-quick@amn0` активна и у `amn0` есть адрес IPv4; `axata` — когда активировано соединение профиля сети: `axata` или `axata-full` (имя активного соединения читается по `nmcli`, а если активного нет — по файлу `/etc/amnezia/profile`). При запасном профиле значок `amn0` MUST быть серым (остановлен намеренно, не ошибка), а его подсказка — «выключен: запасной профиль»; красным он становится только из-за ошибки действия. Подсказка MUST показывать имя туннеля, состояние, страну `amn0`, адрес, имя активного профиля сети («основной» или «запасной»), причину отсутствия связи и текст ошибки.

Цвет значка MUST браться из `Theme`; другие плитки панели `Theme.brightGreen` не используют:

| Состояние | Цвет |
|---|---|
| поднят | `Theme.brightGreen` (#98D048, цвет молний обоев) |
| поднимается | `Theme.yellow` (#E0AF68, цвет рамки плиток) |
| поднят, связи нет | `Theme.orange` (#FF9E64) |
| не поднят | `Theme.gray` |
| ошибка | `Theme.red` |

#### Scenario: Оба туннеля подняты
- **WHEN** служба `awg-quick@amn0` активна с адресом 100.99.53.219 и страной «Франция», соединение `axata` активировано
- **THEN** первые два значка трея — ярко-зелёные символ Amnezia и 󰦝; наведение на верхний показывает «Amnezia amn0: поднят, Франция, 100.99.53.219»

#### Scenario: Ошибка службы
- **WHEN** служба `awg-quick@amn0` в состоянии `failed`, или `axata` не активно, а `axata-vpn.service` в состоянии `failed`
- **THEN** глиф соответствующего туннеля красный

#### Scenario: Запасной профиль
- **WHEN** файл профиля содержит `backup`, служба `awg-quick@amn0` в состоянии `inactive`, соединение `axata-full` активировано
- **THEN** значок `amn0` серый, его подсказка — «выключен: запасной профиль», значок `axata` ярко-зелёный, его подсказка называет «запасной» профиль

### Requirement: Состояние туннелей по событиям
Состояние значков MUST обновляться только по событиям, без таймеров и опроса: `amn0` — по строкам `ip monitor link address`, `journalctl -f -u awg-quick@amn0.service` и `inotifywait` (хранилище приложения AmneziaVPN, `/etc/amnezia/country.json` и `/etc/amnezia/profile`), `axata` — по потоку `nmcli monitor` панели, `journalctl -f -u axata-vpn.service` и `journalctl -f -t nm-openvpn`; строка `inotifywait` о файле профиля MUST перечитывать состояние обоих туннелей. Завершившийся поток MUST запускаться заново сразу, после пяти мгновенных выходов подряд — предупреждение в журнал.

#### Scenario: Служба amn0 остановлена
- **WHEN** служба `awg-quick@amn0` останавливается
- **THEN** значок `amn0` становится серым по событию `ip monitor`, без ожидания интервала опроса

#### Scenario: Смена профиля из терминала
- **WHEN** в терминале выполняется `sudo -n /usr/local/sbin/net-profile backup`
- **THEN** `qs -c panel ipc call tunnels state` после замены файла профиля показывает `profile` равным `backup`, без ожидания интервала опроса

#### Scenario: Отсутствие опросов
- **WHEN** состояние туннелей не меняется в течение минуты
- **THEN** панель за это время не запускает ни одного процесса, кроме постоянно открытых потоков `nmcli monitor`, `ip monitor`, `inotifywait` и трёх `journalctl -f`

### Requirement: Действия туннелей
Правый клик по значку MUST открывать меню действий. `amn0` при основном профиле: «Перезапустить» и «Остановить», если туннель поднят, поднимается или служба активна, иначе «Запустить», «Страна туннеля…» и «Обновить списки стран»; при запасном профиле меню `amn0` MUST содержать только пункт «Основной профиль». `axata`: «Отключить» или «Подключить» (для соединения профиля, активного или выбранного файлом) и «Настройки» (`nm-connection-editor` открывает соединение этого профиля). Пункты смены профиля — в требовании «Профиль сети в панели». Действия и чтение сведений MUST NOT спрашивать пароль: команды root — `sudo -n` по правилу `/etc/sudoers.d/amn-switch` с точными аргументами. Неудачное действие MUST окрашивать значок ошибкой до успешного действия или подъёма; второе действие над туннелем MUST NOT запускаться, пока выполняется первое.

#### Scenario: Остановка и запуск amn0 из меню
- **WHEN** пользователь выбирает «Остановить» в меню значка `amn0`, а затем «Запустить»
- **THEN** пароль не спрашивается, служба останавливается и запускается снова, а меню после остановки предлагает «Запустить»

#### Scenario: Неудачное подключение axata
- **WHEN** «Подключить» в меню `axata` завершается ошибкой `nmcli`
- **THEN** значок `axata` красный, подсказка показывает последнюю строку ошибки

#### Scenario: Служба amn0 активна без устройства
- **WHEN** служба `awg-quick@amn0` активна, а устройства `amn0` нет
- **THEN** значок красный, меню предлагает «Перезапустить» и «Остановить»

#### Scenario: Меню amn0 при запасном профиле
- **WHEN** файл профиля содержит `backup`, и пользователь кликает правой кнопкой по значку `amn0`
- **THEN** меню состоит из одного пункта «Основной профиль», пунктов «Запустить», «Страна туннеля…» и «Обновить списки стран» нет

## ADDED Requirements

### Requirement: Профиль сети в панели
Меню значков `amn0` и `axata` MUST содержать пункт смены профиля: «Запасной профиль: всё через axata» при основном и «Основной профиль» при запасном. Пункт MUST выполнять `sudo -n /usr/local/sbin/net-profile backup` или `net-profile main` процессом панели без пароля; пока идёт переход, оба значка MUST быть заняты. При ненулевом коде последняя строка вывода ошибок MUST становиться ошибкой обоих значков до следующего успешного действия.

#### Scenario: Переход на запасной профиль из меню
- **WHEN** пользователь выбирает «Запасной профиль: всё через axata» в меню значка `axata` при основном профиле
- **THEN** пароль не спрашивается, значки заняты до конца перехода, затем `qs -c panel ipc call tunnels state` показывает `profile` равным `backup` и `connection` равным `axata-full` у `axata`, значок `amn0` серый

#### Scenario: Отказ перехода
- **WHEN** `net-profile backup` завершается ненулевым кодом
- **THEN** оба значка красные, подсказка показывает последнюю строку ошибки, пункт меню остаётся «Запасной профиль: всё через axata»

### Requirement: Профиль в сведениях и проверке панели
Профиль MUST быть виден в окнах сведений: у `amn0` — строка «Профиль», у `axata` — строки «Профиль», «Соединение» (имя активного соединения), «Маршрут по умолчанию» и «DNS». Состояние каждого туннеля в `tunnels state` MUST содержать поля `profile` и `connection`; действия профиля MUST запускаться командами `tunnels run axata 'Запасной профиль: всё через axata'` и `tunnels run amn0 'Основной профиль'`.

#### Scenario: Окно сведений axata при запасном профиле
- **WHEN** запасной профиль поднят, и пользователь кликает левой кнопкой по значку `axata`
- **THEN** окно показывает «Профиль — запасной», «Соединение — axata-full», маршрут по умолчанию через `tun0` и серверы DNS 10.200.115.1 и 10.200.115.2

#### Scenario: Состояние через IPC
- **WHEN** выполняется `qs -c panel ipc call tunnels state` при запасном профиле
- **THEN** JSON содержит `"profile":"backup"` у обоих туннелей и `"connection":"axata-full"` у `axata`
