## MODIFIED Requirements

### Requirement: Туннели при загрузке системы
Туннели MUST подниматься системой при загрузке, без входа в сессию, по профилю сети из `/etc/amnezia/profile` (спецификация network-profiles). При основном профиле `amn0` поднимается службой `awg-quick@amn0`; при запасном служба MUST пропускаться условием запуска (`ExecCondition`, состояние `inactive`, не `failed`). `axata-vpn.service` MUST активировать от root, без агента секретов, соединение профиля (`axata` при основном профиле, `axata-full` при запасном), если ни одно из них не активно, и поднимать его снова после перезапуска NetworkManager. Ожидание MUST идти по событиям (`nm-online -s`, `nmcli --wait`), без циклов с паузой. Сессия MUST NOT поднимать VPN; `kozloff-de` MUST NOT подниматься автоматически.

#### Scenario: Загрузка с работающей сетью
- **WHEN** станция загружается при работающем проводном соединении и основном профиле
- **THEN** `systemctl is-active awg-quick@amn0 axata-vpn` даёт `active`, `nmcli -t -f NAME con show --active` содержит `axata` и не содержит `axata-full` и `kozloff-de`

#### Scenario: Загрузка при запасном профиле
- **WHEN** файл `/etc/amnezia/profile` содержит `backup`, и станция загружается при работающей сети
- **THEN** `systemctl is-active awg-quick@amn0` даёт `inactive`, `systemctl is-active axata-vpn` даёт `active`, `nmcli -t -f NAME con show --active` содержит `axata-full` и не содержит `axata`, `nft list table inet amn` с правами root отказывает

#### Scenario: VPN уже активен
- **WHEN** `axata` или `axata-full` уже активно к моменту запуска `axata-vpn.service`
- **THEN** юнит пропускает запуск по условию и соединение не переподключает

### Requirement: Вход после туннелей
Экран входа greetd MUST ждать подъёма туннелей выбранного профиля порядком systemd (юнит `tunnels-before-login.service`): `amn0` и `axata` при основном профиле, `axata-full` при запасном (служба `awg-quick@amn0`, пропущенная условием, ожидание не задерживает). Поэтому herdr, его обновление в предстартовой подготовке и браузеры, которые открывает демон workspaced в сессии, стартуют уже с туннелями. Ожидание MUST быть ограничено 105 с от начала загрузки: туннель, не поднявшийся за это время, MUST NOT задерживать вход дальше и продолжает подниматься, а его значок в трее показывает состояние.

#### Scenario: Туннели подняты до входа
- **WHEN** станция загрузилась, и сессия запущена автовходом
- **THEN** в журнале загрузки `Finished` у `awg-quick@amn0` и `axata-vpn` стоит раньше запуска `greetd.service`

#### Scenario: Вход при запасном профиле
- **WHEN** файл профиля содержит `backup`, и станция загрузилась
- **THEN** `Finished` у `axata-vpn` стоит раньше запуска `greetd.service`, а `awg-quick@amn0` в журнале загрузки пропущен условием и вход не задерживает

#### Scenario: Сервер axata недоступен
- **WHEN** сервер `axata` не отвечает при загрузке
- **THEN** экран входа появляется не позже чем через 105 с от начала загрузки, проводное соединение и `amn0` работают (при запасном профиле — только проводное соединение), а значок `axata` в трее показывает ошибку
