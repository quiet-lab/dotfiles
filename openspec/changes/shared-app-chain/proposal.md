## Why

В workspace `surf` у пользователя два экземпляра Chrome с разными профилями:
`chrome-ai` (профиль AI.dev2026, клавиша Super+V) и будущий `chrome-ai2`
(профиль «AI2»). Пользователь 17.10.2026 попросил, чтобы у обоих была одна
клавиша Super+V в `surf`, а повторные нажатия переключали их окна
по очереди.

Сейчас так сделать нельзя: проверка конфига отклоняет две записи одного
workspace с одинаковым ключом («workspace surf: приложения chrome-ai
и chrome-ai2 имеют одну цепочку»), а цикл клавиши приложения идёт только
по экземплярам одного приложения.

## What Changes

- Несколько записей одного workspace могут иметь одну цепочку — ключ
  `chain` записи или собственную клавишу приложения. Проверка конфига
  принимает такой конфиг, если режим клавиши (`mode`) у этих записей
  совпадает; разные режимы отклоняются с указанием workspace, обоих
  приложений и цепочки. Клавиша окна-переключателя по-прежнему своя.
- Клавиша, на которую в workspace откликаются несколько записей, ведёт
  один общий цикл по окнам всех этих приложений: по порядку записей
  раздела, внутри приложения — по порядку экземпляров, с прежними
  правилами шага, prev и конца цикла.
- Приложение группы без окон цикл пропускает; запускается первое
  по порядку записей, только если окон нет ни у одного приложения группы.
  Поднятие workspace по-прежнему запускает каждое приложение без окон.
- `workspaced key --new` по общей цепочке открывает новый экземпляр
  приложения активного окна, если оно из группы, иначе первого.
- Собственная клавиша приложения группы, перетаскивание и открытие
  приложения в другом workspace, поднятие workspace, откликающегося
  на клавишу, не меняются.
- Окно подсказки клавиш показывает одну строку: «chrome-ai, chrome-ai2
  в workspace surf»; цепочка с выходом `[sticky.apps]` наследует букву
  один раз.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `ws-daemon`: требование «Цепочка приложения» — общий цикл группы записей
  с одной цепочкой. Дельта перенесена в изменение `home-mode-layout`
  и вошла в основную спецификацию с его архивацией.
- `ws-config`: требование «Цепочки клавиш и привязки» — несколько записей
  одного workspace с одной цепочкой допустимы при одном режиме;
  требование «Перечень клавиш для подсказки» — описание строки общей
  клавиши.

## Impact

- Демон workspaced (`~/work/pets/workspaced`): `config.rs`
  (`Config::responders`), `keys.rs` (проверка вместо отказа),
  `daemon.rs` (`key_group`, `group_windows`, `cycle_group`,
  `next_app_window` по группе, `--new` у приложения активного окна),
  `keys_help.rs` (описание строки), `README.md`.
- Конфиг `dot_config/workspaced/config.toml` в этом изменении не меняется:
  запись `chrome-ai2` добавляется после переезда профиля «AI2»
  в собственный каталог данных (решение пользователя ещё не принято).
- Документация: `docs/window-model.md`, `AGENTS.md`.
