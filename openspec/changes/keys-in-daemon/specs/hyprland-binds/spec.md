## MODIFIED Requirements

### Requirement: Соответствие привязкам Openbox
Конфиг демона workspaced (`~/.config/workspaced/config.toml`, раздел `[[binds]]`) MUST задавать привязки с теми же сочетаниями, что в `rc.xml` Openbox, и с тем же результатом; `hyprland.lua` MUST NOT содержать собственных привязок, кроме загрузки кода привязок от демона:

| Сочетание | Действие |
|---|---|
| Super+Return | запуск `wezterm-gui` |
| Super+R | лаунчер `rofi -show drun` |
| Super+E | файловый менеджер thunar |
| Super+C | закрыть активное окно |
| Super+V | меню буфера обмена (история cliphist через rofi, выбранная запись вставляется в буфер) |
| Super+F | переключить полноэкранный режим |
| Super+X | переключить максимизацию |
| Super+Z | спрятать активное окно в специальный рабочий стол без перехода за ним |
| Super+Shift+Z | показать или скрыть специальный рабочий стол со спрятанными окнами |
| Super+стрелки | перенести фокус на соседнее окно в направлении стрелки |
| Super+Shift+Влево / Вправо | активное окно занимает левую / правую половину рабочей области командой демона `half` с отступом 10 px от краёв и между окнами, тем же, что между плитками панели |
| Super+Shift+Вверх / Вниз | активное окно занимает верхнюю / нижнюю половину рабочей области с теми же отступами |
| Super+1…8 | перейти на рабочий стол 1…8 |
| Super+Shift+1…8 | перенести активное окно на стол 1…8 и перейти вслед за ним |
| Alt+Tab, Alt+Shift+Tab | переключить фокус на следующее / предыдущее окно текущего стола с подъёмом окна наверх |
| Super+L | заблокировать сессию командой `loginctl lock-session` |
| Print, Ctrl+Print, Shift+Print | скриншот экрана, с обратным отсчётом, области |
| Ctrl+Escape, Ctrl+Return, Ctrl+Пробел, Ctrl+Shift+Пробел | dunstctl history-pop, context, close, close-all |
| XF86AudioRaiseVolume / LowerVolume / Mute | `~/.scripts/change-volume.sh` с аргументами `+`, `-`, `0` |
| XF86MonBrightnessUp / Down | `~/.scripts/change-brightness.sh` с аргументами `+`, `-` |
| XF86AudioPlay / Stop / Prev / Next | playerctl play-pause, stop, previous, next |
| Super+левая кнопка мыши | перемещение окна перетаскиванием |
| Super+правая кнопка мыши | изменение размера перетаскиванием |

Служебные привязки, которых в Openbox не было (Super+M — выход из сессии, Super+Shift+C — переключение аппаратного и программного курсора), MUST задаваться в том же файле. Рабочая область — площадь монитора за вычетом зон, зарезервированных слоями (панелью).

#### Scenario: Окно в половину рабочей области
- **WHEN** при активном плавающем окне нажато Super+Shift+Влево, зарезервированных зон нет, `gap = 5`
- **THEN** окно получает положение 10,10 и размер 1905×2140 на мониторе 3840×2160

#### Scenario: Перенос окна на стол
- **WHEN** при активном окне нажато Super+Shift+3
- **THEN** окно оказывается на столе «3», стол «3» становится активным, окно остаётся в фокусе

#### Scenario: Блокировка
- **WHEN** нажато Super+L
- **THEN** экран закрывает hyprlock, после ввода пароля сессия продолжается со всеми окнами

#### Scenario: Привязок в конфиге Hyprland нет
- **WHEN** выполнен поиск `hl.bind` в `~/.config/hypr/hyprland.lua`
- **THEN** совпадений нет, а `hyprctl binds` содержит все сочетания из таблицы

### Requirement: Привязки, не переносимые из Openbox
Сочетания Openbox, у которых нет смысла в Hyprland, MUST быть перечислены в списке `reserved` раздела `[keys]` конфига демона с комментарием, почему они свободны: Alt+Пробел (меню окна), Alt+Super+Пробел (корневое меню), Super+T (рамки окна), Super+D (показать рабочий стол); там же MUST быть перечислены сочетания карты XKB Super+Пробел, Alt+E и Alt+R. Проверка конфига MUST отклонять привязку на любое из этих сочетаний, а конфиг MUST NOT назначать их действиям без отдельного решения.

#### Scenario: Сочетание без действия
- **WHEN** нажато Super+T
- **THEN** ничего не происходит, `hyprctl binds` не содержит этого сочетания

#### Scenario: Попытка занять зарезервированное сочетание
- **WHEN** в `[[binds]]` добавлена запись с `chain = "SUPER+D"` и выполнена `workspaced check`
- **THEN** команда завершается с ошибкой, называющей `SUPER+D` как зарезервированное, демон продолжает работать с прежним конфигом

## REMOVED Requirements

### Requirement: Цепочки клавиш демона workspaced
**Reason**: Требование описывало загрузку только цепочек демона при сохранении собственных привязок в `hyprland.lua`; теперь из конфига демона загружаются все привязки, и требование заменено на «Привязки из конфига демона».
**Migration**: Привязки из `hyprland.lua` переносятся в `[[binds]]` конфига демона, блок загрузки в `hyprland.lua` остаётся и получает запасной путь через сохранённую копию кода.

## ADDED Requirements

### Requirement: Привязки из конфига демона
Конфиг Hyprland MUST при каждой загрузке выполнять код привязок, который печатает `workspaced keys --lua`: прямые привязки одиночных сочетаний и подкарты цепочек workspace, приложений, служебных действий и записей `[[binds]]`. Цепочка MUST работать как последовательность: первое сочетание открывает подкарту, последующие ведут глубже, последнее выполняет действие и закрывает подкарту; `Escape` в подкарте MUST закрывать её без действия. Если команда завершилась ошибкой или недоступна, конфиг Hyprland MUST загрузить копию кода из `~/.local/state/workspaced/keys.lua`, записать причину в журнал и показать уведомление; если копии нет, конфиг MUST загрузиться без привязок с уведомлением об этом. Сочетания из списка `reserved` MUST NOT появляться в `hyprctl binds`.

#### Scenario: Цепочка workspace
- **WHEN** в конфиге демона у `dev-front` задано `chain = "SUPER+W f"` и нажато Super+W, затем f
- **THEN** `dev-front` поднят на активном столе, подкарта закрыта, следующее нажатие f печатает букву в окне

#### Scenario: Escape закрывает подкарту
- **WHEN** нажато Super+W, затем Escape
- **THEN** ничего не поднимается, `hyprctl submap` (или эквивалентная проверка) показывает отсутствие активной подкарты

#### Scenario: Ошибка конфига демона
- **WHEN** в конфиг демона внесена ошибка и выполнена `hyprctl reload`
- **THEN** перезагрузка завершается, все привязки из таблицы Openbox работают как до правки, на экране уведомление об ошибке, в журнале Hyprland сообщение от `workspaced keys`

#### Scenario: Демон отсутствует и копии нет
- **WHEN** `workspaced` нет в `PATH`, файла `keys.lua` нет и выполнена `hyprctl reload`
- **THEN** перезагрузка завершается, `hyprctl binds` пуст, на экране уведомление о том, что привязки не загружены
