## MODIFIED Requirements

### Requirement: Файлы сессий
Сессии MUST храниться в `~/.local/state/workspaced/sessions/<имя>.toml`, по файлу на сессию. Файл MUST содержать: время снимка, номер активного стола, для каждого стола список workspace по порядку и активный, для каждого workspace назначение приложений по ячейкам, и список окон: для окна приложения — имя приложения, стол или `pool`, прямоугольник; для постороннего окна — стол, командную строку, каталог и прямоугольник. Поле `workspace` у постороннего окна в снимках прежних версий MUST читаться без ошибки и MUST NOT учитываться и записываться. Сессия `default` MUST записываться демоном не позднее чем через секунду после любого изменения состояния (поднятие, обмен, открытие, закрытие и перемещение окна, смена активного стола). Именованная сессия MUST записываться только по команде `session save <имя>` или из окна выбора и MUST быть копией текущего состояния на момент команды.

#### Scenario: Автосохранение
- **WHEN** пользователь поднял `dev-front` на столе 1
- **THEN** не позднее чем через секунду `default.toml` содержит стол 1 с активным `dev-front` и его окна с прямоугольниками

#### Scenario: Именованный снимок
- **WHEN** выполнена `workspaced session save review`
- **THEN** появляется `review.toml` с тем же содержимым, что у `default.toml` на этот момент; дальнейшая работа его не меняет

#### Scenario: Снимок прежней версии с привязками
- **WHEN** в `default.toml` у постороннего окна записано `workspace = "work"`
- **THEN** демон читает снимок, ставит окно на его место на столе, но к `work` не привязывает; после следующей записи снимка поля `workspace` у окна нет
