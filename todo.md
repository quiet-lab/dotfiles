### Как проверить

```bash
openspec validate app-families --strict   # артефакты изменения согласованы
openspec status --change app-families --json
system/modprobe.d/nvidia-vrr.sh status    # после перезагрузки ожидается conceal_vrr_caps = N, vrr_capable у DP-2 = 1
system/modprobe.d/nvidia-vrr.sh restore   # откат: вернуть файл, пересобрать initramfs, затем перезагрузка
chezmoi status && git status -sb          # расхождений и незакоммиченного быть не должно
```

### Что пробовали и отвергли

- Относить окно браузера, открытое по Ctrl+N, к приложению активного окна: окно другого профиля из меню аккаунтов совпадает по pid, классу и предыдущему активному окну, ошибка остаётся незамеченной. Подробности и остальные способы различения профилей — в `docs/window-model.md`.
- Правило окна `focus_on_activate = false` для Telegram: отключило бы и переход к топику по клику на уведомление; всплытие убрано настройкой Telegram «Подсветка окна».
- Пересборка initramfs только для отдельных ядер: возможна лишь через внутренний протокол pacman-хука, используется штатная `limine-mkinitcpio`.

Замысел целиком и серия из семи изменений OpenSpec описаны в [`docs/window-model.md`](docs/window-model.md); там же предложения, ждущие подтверждения, и две пробные задачи, которые нужны до шагов 1 и 3.
