## Цель

Проверить после ближайшей перезагрузки, нужен ли ещё параметр драйвера NVIDIA `conceal_vrr_caps=1`. Система к проверке подготовлена; другой незавершённой работы нет, активных изменений OpenSpec нет.

## Где остановились

- 21.09.2026 файл `/etc/modprobe.d/nvidia-vrr.conf` убран, initramfs трёх загрузочных ядер пересобран без него (`limine-mkinitcpio`), записи limine на месте. До перезагрузки модуль работает с прежним значением (`conceal_vrr_caps = Y`), перезагрузка не выполнялась.
- Копия файла и сценарий `remove`/`restore`/`status` лежат в `system/modprobe.d/`; откат проверен вживую.
- Ошибка `module not found: 'nvidia'` для ядра `linux-cachyos-bmq-lto` в выводе пересборки к проверке не относится: для этого ядра нет модулей NVIDIA, его образ не собирается с 04.08.2026, загрузочной записи у него нет.

## Команды проверки

```bash
system/modprobe.d/nvidia-vrr.sh status    # после перезагрузки ожидается conceal_vrr_caps = N, vrr_capable у DP-2 = 1
system/modprobe.d/nvidia-vrr.sh restore   # откат: вернуть файл, пересобрать initramfs, затем перезагрузка
chezmoi status                            # расхождений быть не должно
git status -sb                            # дерево чисто, отставания от origin нет
```

## Отвергнутые решения

- Пересборка initramfs только для отдельных ядер: возможна лишь через внутренний протокол pacman-хука `limine-mkinitcpio-install`, поэтому используется штатная команда `limine-mkinitcpio`, собирающая образы всех ядер.
