### Где остановились

- Демон работает на коде коммита `7eb4f03` (`~/work/pets/workspaced`, `master`, 54 теста): окна и ожидания приложений, исчезнувших из конфига, освобождаются при перечитывании; окно из песочницы flatpak записывается командой `flatpak run`; на одну запись workspace одно перечитывание; обмен ячеек по клавише приложения пишется в журнал. Активных изменений OpenSpec нет.
- В сессии сейчас окна Alacritty и Postman приняты в `work` как дополнительные приложения сессии (остались после проверок); конфиг они не трогают, снять их можно закрытием окон.
- Раскладка фиксируется по Super+Alt+E и Super+Alt+R (изменение `layout-keys-super-alt` заархивировано, проверено пользователем). Hyprland не перечитывает карту `kb_file` после правки файла — приём в [`docs/agent-session-tips.md`](docs/agent-session-tips.md), раздел «Перезагрузка конфига».
- `~/.claude/settings.json` по решению пользователя хранится в chezmoi целиком (`dot_claude/settings.json`); после правок самим Claude Code его забирать через `chezmoi re-add`.
- Панель Quickshell работает на коде без таймеров (коммит `5f1e4ff`): переподключение к демону проверено; подсказки, меню и панель громкости мышью пользователь ещё не проверял. Три опроса с меткой `WARNING` (датчики, диски, погода) — см. [`docs/decisions/0007-no-timers.md`](docs/decisions/0007-no-timers.md).

### Как проверить

```bash
openspec list                              # активных изменений нет
systemctl --user is-active workspaced.service quickshell-panel.service
ss -xp | rg workspaced/sock                # ESTAB — панель подключена к демону
workspaced status --json | jq -c '.pending, .desktops["1"].workspaces[0].apps'
workspaced keys --list | rg 'save-'        # две цепочки SUPER+CTRL+s …
system/modprobe.d/nvidia-vrr.sh status    # после перезагрузки ожидается conceal_vrr_caps = Y, vrr_capable у DP-2 = 0
chezmoi status && git status -sb          # расхождений и незакоммиченного быть не должно
```

### Что пробовали и отвергли

- Относить окно браузера, открытое по Ctrl+N, к приложению активного окна: окно другого профиля из меню аккаунтов совпадает по pid, классу и предыдущему активному окну, ошибка остаётся незамеченной. Подробности и остальные способы различения профилей — в `docs/window-model.md`.
- Правило окна `focus_on_activate = false` для Telegram: отключило бы и переход к топику по клику на уведомление; всплытие убрано настройкой Telegram «Подсветка окна».
- Помечать таймеры панели `FIXME` и исправлять потом: пользователь велел заменять событием сразу, метка допустима только как след в чужом коде (`docs/decisions/0007-no-timers.md`).
- Переподключение панели к демону таймером: объект `Socket` Quickshell 0.3.1 после неудачной попытки не оживает, нужно пересоздавать его по событию.
- Судить о загрузке новой карты XKB по `hyprctl devices` или по работе нового сочетания: список раскладок берётся из той же старой карты, а старый тип клавиши срабатывал и с лишним модификатором. Различает карты только нажатие, которое в новой карте перестало действовать.
- Хранить `~/.claude/settings.json` сценарием `modify_`, который лишь подключает хуки: пользователь решил держать файл целиком.

### Демон workspaced

- [ ] Новая модель окон: семейства и варианты, цикл по клавише, принятие окон в активный workspace, общие окна. Замысел целиком и серия из семи изменений OpenSpec описаны в [`docs/window-model.md`](docs/window-model.md); там же принятые предложения и две пробные задачи, которые нужны до шагов 1 и 3.
- [ ] Демон не переживает сессию, в которой у активного workspace нет монитора (экран выключен, Hyprland на выходе FALLBACK): восстановление сессии падает на `hl.dsp.focus({ workspace = … })` с ошибкой «Workspace has no monitor», и юнит после пяти попыток встаёт в `failed`. Обнаружено 22.09.2026 при перезапуске юнита с выключенным экраном; то же случится при перезаходе в сессию без монитора. Нужно либо откладывать восстановление до появления монитора, либо не считать эту ошибку смертельной.
- [ ] Запускать приложения в отдельный transient scope (`systemd-run --user --scope` или эквивалент через D-Bus), чтобы при `KillMode=process` они не оставались в cgroup демона: systemd при следующем старте пишет «Found left-over process», а память приложений учитывается демону.
- [ ] `Alt+Tab` обходит окна стола по порядку создания (`stable_id`). Если захочется порядок «по последнему использованию», нужен обработчик с удержанием Alt (флаг `release`) либо команда демона с собственной историей фокуса.
- [ ] Обход окон стола стрелками вместо `Alt+Tab`: вверх и влево — к предыдущему окну, вниз и вправо — к следующему. Отложено на отдельное обсуждение 2026-09-16.
- [ ] Парковать вытесненные окна за краем экрана, а не на `special:pool`: Hyprland сохраняет положение окна, вынесенного за пределы экрана (проверено 2026-09-16). Отложено на отдельное обсуждение.
